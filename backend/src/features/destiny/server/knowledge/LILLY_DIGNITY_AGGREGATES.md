## 七曜按星体去重与整盘昼夜共识

七曜只计太阳、月亮、水星、金星、火星、木星、土星，不计交点与外行星。对每颗星核对庙、擢升、三分主、界、面，任有一项即计该星一次；失势或落陷不是正面尊贵，但也不会抹去同时存在的本界或本面。

“任一尊贵”复用原有漂泊的完整反面：漂泊为五项均无，明确不漂泊才证明至少一项存在；未知状态不能取反成肯定。它不等于整体强度、相对更强、幸运、性格或现实身份。

昼夜未知时，先分别计算完整昼盘、夜盘的七星计数，再比较总数。不能先丢弃每颗星有分歧的三分主结果后计数。例如测试中太阳255°与月亮155°分别只在昼／夜有三分主，水星165°具庙与擢升、金星31°有庙，另三曜无正面尊贵：昼夜的成员不同，但总数都为3，仍可确认数量；水星多项尊贵也只计一次。若两个完整数量不同，或缺任一星的位置／源表，数量保持未知。

数量事实只在已确认热带黄道、七曜资料完整且无冲突时生成。原句3／4保持精确数量，5颗不会作为“至少三颗”误匹配；原列历史宫制前提也保留。客户端传入数量或其缺席声明均丢弃后重算。

## 已确认星座足以确定庙位

庙主在同一星座内恒定。单向庙位及明确的庙位互容可用已确认的唯一星座从SQLite原表读取庙主；无须补造黄经，也不要求接纳方本人的位置来判断客星位于谁的庙。

对只有星座的输入，取该星座0度作为**查表锚点**，只读取庙位列，不把0度作为天体坐标输出，不借该锚点计算界、面、相位或实际宫位。若原输入还含矛盾／无效度数，不能退回星座掩盖冲突；多个不同星座也保持未知。

因此未知出生时间仍可以使用已经确认不变的庙位星座；需要精确黄经、太阳相对方位、界、合相或实际宫位的其他本批条件继续缺证据。旧第十四批的水星居月庙、太阳居月／水庙也采用同一规则；未把其合相或其他宫位关系改成星座判断。
