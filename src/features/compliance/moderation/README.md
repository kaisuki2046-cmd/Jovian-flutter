# Moderation System｜内容审核子系统

状态：**暂缓建设，未新增接口、规则、模型调用或日志**。

与 Agreement System 相对独立。其长期职责可包含输入审核、输出审核、风险识别、审核决策和审计，但不属于本轮协议文档任务。

按用户最新指令：

- 算事已存在问题检查逻辑，本轮保留原状；没有确认它已覆盖所有风险，也不称为完整合规审核系统。
- 不为命理、运势、合盘新增内容审核接线。
- 不实施之前讨论的 DeepSeek Flash 问题审核调用。
- 不检查、覆盖或补审历史报告。
- 不建立审核拦截后自动重新生成的流程。
- 生命周期、财产、政治等话题不在本轮转化为新增的全局关键词规则。

以后如重启该子系统，需用户重新明确范围。内容审核与向第三方 AI 发送个人数据的告知、授权不同：暂停前者不表示可以跳过后者。后台管理逻辑可隐藏，但不能对用户或 App Review 隐瞒实际数据处理和功能。

## 上架适用性补记

2026-11-18 对照[Apple 当前 1.2 条款](https://developer.apple.com/app-store/review/guidelines/#user-generated-content)：其中明确包含 AI 内容创作应用。因此不能只因没有社交功能就认为当前生成内容无需核对相关保护措施，也不能称算事现有关键词检查已足够满足上架要求。

过滤、举报、及时处理、滥用用户处置和公开联系方式等，应按实际功能逐项评估并记录缺口。用户本轮只授权写文档，故这里只登记；不新增审核 API、规则、全局敏感词、模型调用或历史报告补审，也不暗中扩大建设范围。详见[表格核对第 3、40、49 行](../reports/COLLEAGUE-CLAUSE-RECONCILIATION.md)。
