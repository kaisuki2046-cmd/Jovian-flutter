# 莉莉本质尊贵表的计算接入

第十三批，核对日期 2026-11-19。批次名称沿用任务开始日 20261118。只修改命理目录，不重算既有归档。

## 原表与可计算范围

采用导入资料中固定的 1659 年第二版 p.104 表段，稳定 ID 为 `astro-lilly-v1-dignity-table-p001-001` 至 `p144-001`，不改原始 JSON。其 144 条包含庙位 12、失势 12、擢升 9（含南北交点两格）、落陷 7、界 60、面 36、昼夜三分主 8。三分主按对应的三个星座展开后，SQLite 共存 160 个单元。

本轮目验并独立转录 [1647 初版 p.104](https://iiif.wellcomecollection.org/image/b30338724_0138.jp2/full/1800,/0/default.jpg)，核对七曜庙主、擢升／失势／落陷、十二座界段、面和昼夜三分主与上述资料表对应。来源仍标为导入资料的版本，计算口径为 `lilly-1659-p104-v1`。原书 [p.112](https://iiif.wellcomecollection.org/image/b30338724_0146.jp2/full/1800,/0/default.jpg) 定义的漂泊要求所在度数没有任何本质尊贵，并举土星在白羊不同度数是否拥有界尊贵的差别。影印仅缓存在忽略的 `.local/research/`，不提交，也没有声称已下载完整 1659 年 PDF。

尊贵计算对象限传统七曜，原表交点格保留作查表出处。交点的黄经与落宫按 [第四十三批](WESTERN_INTEGRATION_RESEARCH.md#第四十三批月交点和原书落宫) 的独立口径计算。庙位列的 D/N 区分昼／夜性庙座，不意味着另一昼夜盘失去入庙资格；三分主才依实际昼夜选择。擢升与落陷按整座判定，未用表列特殊度数替代整座条件。界、面按星座内实际度数取左闭右开区间：白羊 6° 已进入下一界；27 度之类原书序数不与零起点数值混淆。

`peregrine` 只在庙、擢升、三分主、界、面五项均为否时成立；失势或落陷不自动取消已经拥有的界／面等本质尊贵。昼夜未知或相互冲突时，分别计算昼、夜，只有一致的判断成为事实。缺黄经、黄道口径、同一天体坐标冲突、星座与黄经冲突或缺完整源表时，不生成相应肯定或否定。未知不是缺席。

## JSON 到实际 SQLite 查询

构建将 144 条原资料编译到同一 `destiny-knowledge.sqlite` 的 `lilly_dignity_cell`，由 `source_id` 保留出处，按星座与度数建立索引。运行时从 SQLite 读取当前位置的单元，不扫描 Claim JSON。表格缺项、区间断裂或重叠时，整次构建事务回滚，原有有效数据库保留。Schema 版本升为 3，源文件／编译代码变化后自动重建。

本批完整回归发现并发构建时，原有只读连接没有繁忙等待设置，可能立即报锁。库存、解释和报告的只读连接现与构建连接同样等待最多 60 秒；独立线程持有并释放排他锁的测试验证等待后读取成功，未改为绕过事务或读取未提交代。

表格资料带 `calculationReference` 元数据；审计的 `calculationReferenceSources` 单独计 144 条。这是参与计算的来源数，与个人解读的索引状态分开统计。没有默认把 `context.lilly_dignity_table` 或 `active_sign` 设为个人命盘条件，没有把查表说明变成性格结论。

普通 `lookup` 与 `explain` 自动通过本次数据库连接重算 `western_lilly_dignity`。客户端传入的派生尊贵及其缺席标记均丢弃，不能绕过计算。未知出生时间按现有服务端规则去除精确黄经，故本轮两条新规则不凭未知时刻触发。

独立核验时可调用 `claimChartContext('western', chart, aspectSelectors, (sign, degree) => catalog.lillyDignityCells(sign, degree))`；第四参数缺省时不计算尊贵，不会从默认库补造证明。新的事实和计算说明已接入中文报告材料，不需要账户或公共 UI 改动。

## 两条新增解读与边界

- `astro-lilly-v3-wit-p005-001`：水星入庙。必要事实由水星实际热带黄经和源表取得，别的天体入庙或孤立派生标记不能代替。
- `astro-lilly-v3-health-servants-p011-001`：保留原列六种风／火星座备选，仍同时要求土星漂泊及莉莉口径第六宫。天秤擢升、水瓶入庙使其相关漂泊备选自然不成立，保留条件，不删除尊贵来制造命中。

两条均由合成出生日期、地点实际排盘，经 SQLite、单条解释进入报告材料，见 [排盘证据](claims/integration-batch-13-witnesses.json)。原有历史智识、家务格言的使用限制继续透传，不能把单项配置变成现实能力或人格评价。

`strong` 未定义为“至少一项本质尊贵”，整体强弱、偶然尊贵、接纳、所选征象星、综合取主、速度与入相分离仍待核定；已有 8 条部分备选记录不因本批而声称完整。查表的 22 条后续查询注记和其他评分资料也没有自动启用。

专项 6 项通过，覆盖原表独立核对、每个界／面的端点、昼夜差异与一致值、未知／冲突／伪造输入、SQLite 热库禁止读 JSON、构建失败保留旧代、独立线程写锁等待、实际排盘到报告与源表范围隔离。全量与类型、边界检查状态见 [接入进度](INTEGRATION_PROGRESS.md)。

## 第一百三十八批·1647 初版的庙座栏标与原表擢升度

采用卷一第 104 页的庙座第二栏及擢升栏，逐条核对 12 个庙座栏标和 9 个表列擢升度。D、N 分别标记同一行星的两庙，巨蟹与狮子的 ND 是日月各自只有一庙的表记。同一星座在昼盘和夜盘得到相同栏标。 [初版影印](https://iiif.wellcomecollection.org/image/b30338724_0138.jp2/full/1800,/0/default.jpg) · [第 104 页转录](https://krasiancientastrology.com/wp-content/uploads/2016/11/CA-I-copy.pdf#page=124)

构建核对各条的来源、条件和原文指纹，并用已入库的尊贵表复核各星座的庙主和各擢升座。表列度数存入统一 SQLite。报告按已确认的热带星座选择对应栏标，按已确认的天体选择专属擢升度。星体位置与该条的表列整度作独立对照。只有落座时，报告列同座资料，省略整度判断。交点沿用排盘引擎的真北交黄经，南交取实际对点。 [月交点排盘口径](WESTERN_INTEGRATION_RESEARCH.md#第四十三批月交点和原书落宫)

八份原生盘例验证全部二十一条经 SQLite 查询、输出实际栏标并对照表列整度。擢升整座及个人断语保留各自的判定口径。第 104 至 105 页另有累计端点的查表说明，仍保留在原书来源清单。 [回归测试](lilly-dignity-references.test.mjs)
