## 来源与解释范围

伴侣资源两条已核对Wellcome原印 [596页](https://iiif.wellcomecollection.org/image/b30338724_0630.jp2/full/1800,/0/default.jpg)、[597页](https://iiif.wellcomecollection.org/image/b30338724_0631.jp2/full/1800,/0/default.jpg)。原书同时要求按当事人的现实处境理解资源，不将历史贫富、门第语言当作绝对社会身份。

其余条件核对所提供[第三卷PDF转录](https://krasiancientastrology.com/wp-content/uploads/2016/11/CA-III.pdf)：p.604明确金星一宫与木星七宫并列；p.614的“在那里”承接九宫，不泛化为任意梦象指征；p.632明确固定组排除天蝎、水土列表不含处女；p.635列出五个友伴宫位。这里的吉星仅木星、金星，凶星仅土星、火星；没有借来现代外行星或其他篇章的不同分类。

职业对象仍使用 [已接入的前两步选星](LILLY_PROFESSION.md)。当前可确认的实际成员可以提供正向证据；后续月亮入相等选星步骤尚未接入，不能由缺少当前成员推成全流程没有职业指征。本篇允许多个成员，不擅自只选一个最强星。

七条记录的组合转换固定出处、条件、证据内容指纹；任意一项变化都会退回来源复核，不套用旧展开。其他篇章不因关键词相同自动采用本组口径。

## 实际查询

组合展开为现有的实际落宫、传统宫主、已确认职业成员与其自身星座等结构化条件；保留原外层AND／OR、性别和Regiomontanus要求。七宫主身份和其八宫位置不能借用另一颗吉星；一颗星的职业成员资格不能与另一颗未选中星的星座拼接。

落宫沿用 [莉莉黄经与宫头前五度规则](../../control/lilly-houses.mjs)，不以整宫制或现代共主替代。来源组合的否定完整展开：存在某一颗星满足条件，其否定必须排除每一颗候选；金星一宫且木星七宫的否定则只需一边有实际反证。未知位置、未知身份不当作否定，原始输入里的派生标记不代替重算。

运行查询、解释及报告仍从统一SQLite读取，JSON仅供审查和重建。中文报告明确这些是历史取象，不作现实资源、生育、友伴或梦境结果的必然判断。
