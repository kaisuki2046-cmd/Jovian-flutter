# 来源与使用边界

- 四库本、紫微古籍和 Leo 1899 年版的新增条目保存结构化条件、自写依据摘要、原始段落定位及现代解读。源站的现代注释、排版和转录许可分别记录。试点使用链接定位和原创释义。
- Renhuai 仓库分别标注代码 MIT、发布数据集 CC BY 4.0 和倪海厦原话 CC BY-NC-SA 4.0，数据集许可排除其中的倪海厦原话。试点条文直接取自古籍核对。 [上游许可](https://github.com/Renhuai123/ziwei-doushu#九协议)
- Swiss Ephemeris 的官方文档列出 AGPL 和 Professional License 两种授权。项目西占仍用 Astronomy Engine。 [官方接口文档](https://www.astro.com/swisseph/swephprg.htm)
- Ptolemy 的古代作品和 Robbins 的现代译本按各自版本登记。此批仅使用书目和段落链接。 [Loeb 1940 版本说明](https://penelope.uchicago.edu/Thayer/E/Roman/Texts/Ptolemy/Tetrabiblos/home.html)

来源和摘录政策为资料库元数据。命中由盘面事实和规则条件决定。
