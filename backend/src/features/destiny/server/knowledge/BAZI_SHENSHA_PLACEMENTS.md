## 计算口径与数据范围

沿用项目 `natal-shensha-v1` 的年、日分别起查，不声称原书各篇已统一年查、日查之争。驿马、华盖分别按来源地支三合组查询，旬空按来源完整干支确定；来源柱本身不能充当自身的驿马、华盖或空亡目标。两种神煞可以来自不同已确认来源柱，但必须实际落在同一个目标柱。两者在不同柱的原生反例不能拼接命中。

复用本模块真实排盘的神煞计算，不读取客户提供的神煞标签或孤立配置标记来决定这几个条件。查询前从已确认的柱、干和支重算，矛盾坐标、不合法干支及五虎遁／五鼠遁冲突不提供新条件。派生标记及其客户声明的缺席均不作为证据。

只使用条件实际需要的数据：目标地支已知即可核落柱；驿马、华盖的来源地支可以单独已知，但旬空需要完整来源干支。已知年支、日支即可核年起驿马是否落日支，不额外要求月、时。未知时辰保留其他已知柱的正向条件，不猜测时柱，也不从未知生成缺席或失败结论。新增正向辅助入口没有改变现有完整来源详情接口的行为。

当前使用统一SQLite查询、解释和报告入口；JSON继续仅供审查和重建。报告只接已确认原句及中文取法限制，不把历史迁居、婚姻或僧道取象写成现实必然结果。
