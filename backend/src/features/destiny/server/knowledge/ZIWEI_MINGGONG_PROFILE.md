## 资料范围与核对

只采用所供资料标注为固定修订 `1963110` 的《紫微斗数全书》卷二「一 命宫」逐星宫位表。通过书名、卷、章、修订链接和 16 个已登记的表段 ID 共同限定，不把同卷入命歌诀、入限歌诀或其他书的明度借来补表。

## 与当前排盘的关系

主星位置、命宫及宫支仍由当前排盘引擎提供；本轮增加的是所据表的明度查取，没有将整套古书安星、闰月及其他规则替换进引擎。软件原有 `palace_brightness` 和其他书的匹配继续保留。

例如当前引擎给天梁丑、未为旺，本表给入庙。源表条件使用单独的 `palace_source_brightness`，包含版本、命宫、星曜、地支、本命层及明度；不能用软件旺档直接满足源表入庙条件。天梁申在本表为陷，同卷后面的歌诀另有不同表述，本配置没有将两者合并。

只对该版对应命宫表段的条件增加或替换源表明度。原句明度作用于所论主星，不自动给同度的另一星附加同档明度。后句「按本篇为旺／陷／得地」保留为可执行条件，绑定前文的同一命宫、星曜和地支；生年、同守星及独守计数仍分别核对。

## 服务端与报告链路

服务端从本命星位和命宫地支重算该组事实。缺星、缺宫支、同宫支冲突、同一星被确认在不同宫、不同宫同时占用命宫地支、非本命层以及表中留空格均不生成该值。未知不等于不满足，也不构成明确的缺席证明。

请求传入的源表明度和相应缺席标记均被移除。时间未知时，命宫及其他依赖时辰的紫微宫位事实不保留，查询端无法用它们重新拼出源表明度。派生结果只在内部检索上下文使用，不增加前端请求字段或放宽请求数量限制。

查询仍经 `lookup`、`explain` 和报告入口。条件及配置变化自动使生成库重建；运行中修改匹配代码后仍按既有约定重启服务，避免新旧函数混用。报告材料将明度标为《全书》命宫表口径，并注明它与软件明度、同卷歌诀分开。命中条件材料使用中文，不包含该事实的机器字段或版本键。
