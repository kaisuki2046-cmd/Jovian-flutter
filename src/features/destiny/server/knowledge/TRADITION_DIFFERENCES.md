# 流派与计算口径

- 八字试点采用《三命通会》的日时月分支，用项目节气月支规范化季节，如夏生对应巳、午、未。月令取格、旺衰平衡和调候各有单独的判断条件，归档来源并保留各自适用范围。
- 紫微以当前 iztro 本命盘为口径。宫支、星曜宫位和 `scope` 取计算结果。同宫用宫名核实，三方和对宫用已确认的宫支距离核实。庙旺、飞化、运限准备好对应事实和计算口径后可另增规则。
- 西占本命盘采用热带黄道和整宫制，五种主要相位的上限为 6°。Leo 的落座条只匹配本命月亮或太阳。Ptolemy 卷三的综合判断涉及水星、月亮以及相关配置，还需额外事实才能用于匹配。 [原书卷三第 13 节](https://penelope.uchicago.edu/thayer/e/roman/texts/ptolemy/tetrabiblos/3d%2A.html)

规则 ID、流派和出处随命中返回。相近说法可按主题归到同一段，条件不同的说法仍保留各自适用情境。

八字第七批沿用 `monthly-weighted-strength-v1` 复核「日主强／旺／衰弱」，并标记为项目既有筛选口径，不能据此声称已覆盖古籍所有旺衰流派。未知时辰时只在确定三柱的十二种合法时柱评估完全一致后保留结论。原句「巳月偏官格」与当前月令本气取格不直接互换；盲派宫星所声明的宫合前提未落实时，单十神不能使整条断语成立，需保留待核原因。

紫微第五批新增的「旺地」「庙地」只对应现行表的旺、庙，不默认扩大为庙旺。文昌、铃星在现行表没有旺档，武曲的旺位又必同天府，因此涉及文昌旺、铃星旺、武曲独守旺的 3 条继续待核另一明度口径，不能仅靠文字已识别就声称可运行。明确原句的星曜备选与同宫要求分别保留。

2026-11-18 三库升级保留上述默认算法口径。后续第四批独立增加 Regiomontanus 宫头与包含天体纬度的三维落宫，仅供明确指定该宫制的资料使用；新增字段与整宫制隔离，不更改默认星盘。已知出生时间且几何可用时才提供该组事实，未知时间、旧盘或尚未支持的极区反向宫序不补造。尚未实现其他 Lilly、Ptolemy 专用判断。八字库新增的铁板条文要求另一套起数体系，不以四柱匹配代替。原库 `ready` 与项目的可计算状态分别记录，详见 [升级与待接入范围](CLAIMS_UPGRADE_2026-11-18.md)。

第六批核对原书本命宫区间后，为莉莉单独接入黄经／宫头前五度判宫、传统庙主和宫主入宫。原三维几何事实保留，莉莉条件改用明确的历史口径字段；不能跨用两种宫号。已接通 32 条新增、修正原有 35 条，仍未实现的相位、界、尊贵综合及其他专用取主法保持待接入，详见 [研究记录](WESTERN_INTEGRATION_RESEARCH.md)。

第八批按莉莉 1647 初版 p.107 分别计算两套容许度，以双方半径之和判定明确相位。相位采用天体黄经，普通六度相位仍保留原字段；同组条件和排除项须用同一套表。善相取六合或拱，合相性质另论；任意成相、partile、角点／交点及入相分离各有尚待核定的语境或算法，见 [研究记录](WESTERN_INTEGRATION_RESEARCH.md)。

紫微第九批沿用 iztro 2.6.5 的星位与亮度，只补齐明确词形，不引入另一套安星表。「同度」「同居」核对同宫；「单守」保留主星计数；「落陷」对应现行陷。宫位已在前句指定时，同居关系绑定该宫。《捷览》「太阴入命吉凶诀」中入庙化权的条件绑定命宫，不从其他宫触发；入庙和化权必须属于同一太阴。原书章节见 [《捷览》太阴星论及入命诀](https://shixingji.club/public/ziweidoushujielan)，同度与命／对宫原句见 [《全书》卷一诸星问答](https://zh.wikisource.org/wiki/紫微斗數全書/卷一)。已识别一个词形并不代表原条目的水乡、男女分支或其他未核前提已经落实，见 [第九批清单](claims/integration-batch-9-20261118.json)。

紫微第十批接通命宫表中明确的多地支、生年及亮度组合。所据《全书》卷二将天梁丑、未列为入庙，而 iztro 2.6.5 两位均为旺，因此该条保留明度差异待核，需独立的原书口径，不能用软件旺档替代入庙。另将《斗数观测录》申命同梁的一例描述保留为历史命例，不凭同一组星位就当成通用性格规则；原例可读，完整上下文与专用检索仍是后续项。详见 [第十批清单](claims/integration-batch-10-20261118.json)。

紫微第十一批为《全书》卷二命宫表建立独立明度版本，只在固定修订、对应表段中使用。源表天梁丑未入庙及申位陷等值与软件默认明度分别保留；同卷歌诀不同表述不合并。只增加明度查表，主星位置仍用现有排盘；9 个未列值保持未知。新增接通 16 条、校正已有 59 条，天梁丑未旧待核项在本批解除，详见 [命宫表来源与边界](ZIWEI_MINGGONG_PROFILE.md)。

紫微第十二批将明确宫位章名／入命诀作为省略语境，显式宫位和身宫变量优先，不根据泛论或命限混合标题猜落宫。六条同居条件收紧到指定宫位；寅申子女宫机梁同居的两条旧匹配退回，现行十二种星系配置中机梁只在辰戌同宫，不能删前提或借另宫同居。武曲陷地的另一条也继续待核，见 [上下文与资料边界](ZIWEI_PALACE_CONTEXT.md)。

西占第十三批独立接入莉莉 p.104 本质尊贵表，采用原资料 1659 版标记，并以 1647 初版原图核对表格。传统七曜的庙、擢升、昼夜三分主、界、面与失势、落陷分别计算；漂泊需要五项本质尊贵均无，未知昼夜只保留两种结果一致的事实。原表 D/N 庙座标注不当作昼夜限制，擢升特殊度数不替代整座。没有把此算法冒充整体强弱、接纳或综合取主。144 条计算资料与新增 2 条个人解读分别统计，详见 [尊贵口径](LILLY_DIGNITIES.md)。

西占第十四批区分单向接纳与明确互容：接纳方／客星顺序保留，互容需两个不同天体各处对方本质尊贵；原句另有相位或渐入时独立要求，不凭互容删前提。日月定位星使用实际光体星座的传统庙主。一般 reception 范围未明时不猜成互容或任意单向关系；家产与远行新记录因此仍各保留一组待核，土星界的一支也未猜测启用。逻辑展开、源表查询及边界见 [接纳口径](LILLY_RECEPTIONS.md)。

八字第十五批按已明确的透干／藏干和原局缺席分别核对，透干沿用年、月、时的口径，裸“见／有”的取用范围不默认解释。每月不同备选及其排除保持独立，新补条件必须允许现有五虎遁／五鼠遁下的合法干支；反证和未知时辰处理见 [八字文字条件](BAZI_LITERAL_CONDITIONS.md)。年／月官印限制在指定同一柱，年克日保留方向；原注示例不冒充额外出生事实。其余未定强弱、制化、宫合及异文仍待核。

紫微第十六批只修复完整星名与明确守宫语法，并将同守绑定到已声明的唯一宫位；不改变安星算法或默认明度。天同命宫表继续采用对应原表，天相“和平”的语义没有据字面猜成软件平档。两条固定编辑说明不扩展成通用忽略规则，见 [完整星名与同守](ZIWEI_PALACE_CONTEXT.md#第十六批完整星名与明确同守)。

八字第十七批按《渊海子平》卷三本篇明确的“一德”接入，不借另一篇“二德全者”更改量词，也不把歧义条目先按较严格条件启用。天德、月德的现有月支取法保留，归禄只核日干临官于时支。新增旺衰断语明确标记项目加权模型，官星沿用正官字段，与七杀及官杀组分开。来源说明和未决两条见 [禄归时与一德](BAZI_LITERAL_CONDITIONS.md#第十七批禄归时与本篇一德)。

八字第十八批明确数量与实际位置分别处理：普通“有两”不额外加最多两处，明示“仅两”保留上限，原句“一二”保留范围。日主不额外充当透干，藏干按含该干的地支处数计数；隔位按四柱位置核对，不等于另行证实合化。多分句原文只传已匹配的原句，未定义“无制”等后句继续待核，见 [数量与独立原句](BAZI_LITERAL_CONDITIONS.md#第十八批数量隔位与独立分句)。

西占第十九批将 Robbins《Tetrabiblos》埃及通行界、古抄本印表界和迦勒底界分开查询。界长须先累计；迦勒底的昼夜差别不覆盖其他两表，未知昼夜只保留该方案的一致结果。源中印表校记与旧转录分别保留，不按一般主宰原则重排印表。这些是实际星体位置的计算参考，不自动成为个人事件或疾病规则，见 [三套界表](PTOLEMY_TERMS.md)。

西占第二十批保留莉莉 p.625 前两步的优先次序与多星同主，日光距离取完整17度；只有第一步全部证伪后才检查有尊贵且不落陷的十宫传统宫主，第二步不附加第一步的日光限制。未知昼夜比较完整流程的一致结果，未完成的第三至第五步保持待定，不能猜成唯一十宫主或三颗均无，见 [职业选星口径](LILLY_PROFESSION.md)。

紫微第二十一批只在当前iztro 2.6.5默认本命配置内检验12种主星布局与六类身宫位置。源句的同宫／对宫、两侧相夹与命／身择一分别绑定位置；《捷览》的已核择一不替代《星诀》归一化中的且，同梁申命原例也没有变成通用断语。组合不相容仅证明与当前算法有冲突，不推定古书错误；见 [来源和位置边界](ZIWEI_RELATIVE_PALACES.md)。

八字第二十二批区分原句所写的“原局同现”与项目的结构成立：藏干余气可以提供同现证据，不能额外加上天干／月令本气锚点；裸结构接口和已有来源保持原口径。官与七杀分开，透干与支藏分开，“藏”未自动附加“不透”，固定辛申例不泛化为任意隔印成功。来源、分句及保留项见 [原局十神与柱位](BAZI_NATAL_GODS.md)。

第二十三批按原句区分生年天干、出生年支与命宫地支；四生只落实寅申巳亥宫位。现行按年干安羊与辰戌生年四库庙羊组合不相容，8个组合保留原句及复核，不改掉年支或降低庙位；廉贞申宫甲庚戊与丙的原书等级分句核对，不能跨等级或混入寅宫句。见 [生年与等级接线](ZIWEI_NATAL_YEARS.md)。

第二十四批星座类别采用莉莉本段明确列表。回归座只取巨蟹、摩羯，不同于四活动座；职业p.632四足组只取白羊、狮子、射手，不借Book I更宽的列表。七宫头、七宫主和太阳只要求同类别，不额外限同一星座；金星定位星按统一库原尊贵表传统庙主，职业类别仍须先核实际指征成员。见 [星座类别接线](LILLY_SIGN_CLASSES.md)。

第二十五批按莉莉p.113明说的同座且不足8°30′计算燃烧，保留原印页10°例句矛盾；光束取17°，日心17′强化优先作为明确标注的推定。东西方位取相对太阳黄经，精确合冲不制造方向证据。快慢以完整24小时实际位移绝对量比较各星原书均值，顺逆另判；不复用一小时差分乘24、不把任一慢行代替七曜全部慢行，也未接通“很快”、可见性或入离相。见 [原页与计算边界](LILLY_SOLAR_MOTION.md)。

第二十七批继续用提供库1659版p.104表，不改换原书版本。七曜拥有任一五项本质尊贵时按星体计一次，精确三／四颗不改成至少三颗；未知昼夜比较完整数量而非先丢弃有分歧的成员。单向庙位只须确认客星星座，零度仅作SQLite查庙位列的锚点，不借来判界、面或相位；原始度数冲突不退回星座。金土界只启用两星均在界且合相的共同可确认范围，原文修饰范围待核仍保留，不从该充分条件反推整句的否定；其他OR支不变。见 [尊贵聚合与单向庙位](LILLY_DIGNITY_AGGREGATES.md)。
