# 命理功能与输入输出

截至 2026-11-12。根据 `E:\app` 当前 `dev` 工作区（起始提交 `454eb17`，含本地并行改动）整理。本文说明源码中的功能和数据边界，不代表线上部署状态。

## 1. 用户输入

| 输入 | 当前规则 |
| --- | --- |
| 出生日期 | 公历年月日，支持 1900 年至设备当天。在日期面板确认后填入表单。 |
| 出生时间 | 出生地当地时间，精确到小时和分钟。没有可回填时间时，滚轮初始停在 12:00，确认才生效。当前表单没有「不知道」选项，仍兼容时分不完整的旧资料。 |
| 出生地点 | 可离线逐级选择或搜索，覆盖中国大陆近 3,000 个已匹配地点，另有纽约、伦敦。排盘使用所选地点的代表坐标和 IANA 时区。 |
| 性别 | 表单提供「女」「男」。旧档案的「其他」仍可读取，重新测算时须重新选择。 |

点击「开始测算」时统一校验四项。当地夏令时造成输入时刻不存在或有两种解释时，页面提示用户核对。经账户授权取得的生日和时分可初始化滚轮，仍须用户确认。已登录用户可在支持 SecureStore 的设备上主动保存或删除本机出生档案。

## 2. 用户输出

成功测算后，命理页显示一份中文解读正文。点正文下方的「查看命盘」，可在弹窗中切换三套盘面。

| 输出 | 本次测算的页面显示 | 从归档回看 |
| --- | --- | --- |
| 解读报告 | 可选中文字的五主题正文，综合、事业、爱情、学业和财富各有小标题。每个主题兼有性格与具体事件、人生轨迹分析；书籍资料不足时依据盘面推演。 | 命理首页显示最近一次已保存的正文，账户历史可查看正文和盘面。旧报告的章节在回读时并入正文。 |
| 八字 | 年、月、日、时四柱卡片；逐柱天干十神（含日主）、藏干及其十神、命中的神煞。神煞范围为天乙贵人、文昌贵人、禄神、驿马、将星、华盖、桃花、空亡。 | 摘要保存四柱。若已保存足够的干支，可据此恢复可确定的十神和神煞。 |
| 紫微斗数 | 农历日期、五行局、十二宫盘、身宫标记。点宫位可看干支、主星、辅星和杂曜，星曜名称旁可显示四化。 | 以基础列表显示宫名、地支和主星。 |
| 西方星盘 | 本命星图、上升、天顶、太阳和月亮等 10 个天体的位置、十二宫和主要相位（合相、六分相、四分相、三分相、对分相）。使用热带黄道、整宫制。 | 以基础列表显示各天体的星座及已确定的宫位。 |

旧资料的出生时刻不完整时，八字显示各候选情景一致的结果；紫微会提示有多个时辰情景，不能确定时不展示单一十二宫盘；西方星盘显示稳定的天体星座，不展示需要精确时刻的星图、上升、天顶、宫位和相位。旧归档缺失的盘面数据会提示，回看时不会用出生资料重新排盘。

## 3. 功能流程

1. **录入和校验。** 用户在命理页确认出生资料，可以查看已保存的本机出生档案并重新核对。
2. **本机排盘。** 根据出生地时区及资料计算八字、紫微斗数和西方星盘。时刻不完整时，先计算有效候选，再取共同成立的事实用于报告检索。
3. **生成报告。** 服务端先将已确认的三套盘面事实转为中文，再将五个主题命中的书籍出处与原文、实际命中条件及现代释义组成精简文本交给 DeepSeek。模型自行组织性格和事件解读，服务端直接返回正文。
4. **取消和手动重试。** 测算可以取消。一次测算只调用模型一次，报告请求失败时可手动重试并复用本次已有盘面。未配置报告服务时无法开始新解读，也没有本机生成报告的备用流程。
5. **保存和回看。** 有效会员或访客会话生成报告后，自动通过账户接口归档。归档成功后，再次进入命理页会读取最近一次结果，不重复排盘或请求 DeepSeek。会员可通过同一账户服务跨设备回看；访客在同一设备上可在 7 天会话有效期内回看。归档暂时失败时，当前报告仍可查看，页面按失败类型提供重试或说明。

## 4. 服务和归档的输入输出

| 接口或数据 | 输入 | 输出或保存内容 |
| --- | --- | --- |
| 本机排盘 | 已确认的出生日期、时间、地点和性别。 | 三套原始盘面及供界面使用的摘要。 |
| `POST /destiny/report` | `timeKnown` 和 `chartQueries`。每种盘最多一项，含 `method`（`bazi`、`ziwei` 或 `western`）、`rulesetVersion`、`confirmedFacts`。没有稳定事实的盘不提交。 | `{ "report": "正文" }` 或 `{ "report": null }`。空结果提示重试。此请求不传原始出生日期、时分、地点或账户身份。 |
| 账户 V1 归档 | 当前报告和排盘摘要，由命理页提交给账户公开接口。 | 测算时间 `calculatedAt`、时刻完整性 `timeKnown`、生成方式 `mode: "deepseek"`、完整正文 `overview`、基础盘面 `charts`。 |

命理解读库共 21,941 条，包括 3,095 条旧规则和 18,846 条新版 Claim，JSON 保留为审查资料源，SQLite 用于运行时检索。模型接收盘面事实的中文描述与实际命中的书籍材料；原始盘面 JSON 和内部索引不写入模型消息。

## 5. 完整盘面归档接入

命理生成报告后，通过账户公开归档请求发送 [完整盘面快照](model/chart-snapshot.ts)。新增字段 `chartSnapshot` 与现有展示行并存，带快照版本、排盘引擎及规则版本、时间采样版本和时刻完整性。八字保存四柱、十神和神煞来源。紫微保存原始十二宫、星曜分类、亮度和四化。西方星盘保存天体原始数值精度的黄经及黄纬、宫位、上升、天顶和相位。

精确时刻保存一套结果。时刻不全时保存各套盘实际算出的候选，并保留采样版本，调用方据此区分完整与不完整时刻。计算失败的盘保留空结果与原因。快照随所属账户的归档详情读取，合盘接入时应沿用账户的身份权限。旧记录只能读取当时保存的展示行。

完整盘面归档以账户回执的 `chartSnapshotSaved: true` 为准。旧服务仍可保存解读和基础盘面，页面会区分这两种结果。合盘通过账户的归档读取接口获取完整盘面。
