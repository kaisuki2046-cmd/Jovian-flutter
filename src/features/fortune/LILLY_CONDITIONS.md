# Lilly 分项偶然条件与逐星正文复核

本轮继续补四条太阳回归资料的计算事实。回归星与本命目标各用自己那张图的同一星历时刻，不将两张图的相位、日光状态、互容或宫位混成一次“受助”。原始资料 JSON 未改，运行匹配仍使用 SQLite；新增 JSON 参考文件只用于核验算法。

## 日光、运动与月亮

- 日心按17角分内单列；同座8.5度内的燃烧与17度内的日光下分开。日心的原始角距也在燃烧范围内，但不能因此同时当作燃烧结论。跨座而角距落入日心范围时，仍保留取法未知。
- 按文字定义计算燃烧，同书另举太阳18度、木星28度的10度例与8.5度定义不一致；该冲突留下审查，不将阈值放大到10度。8.5度和17角分取含端点，日光距离17度取不含端点，是明确的本次比较约定。
- 速度为同一时刻前后各10分钟黄经的中央差分，保留正负方向。均速按原书度分秒转换；绝对运动量与均速的比较，不改变实际顺逆行。瞬时近零不冒称已找到原书数日停驻段。
- 月亮增减光由本图日月黄经相位区分。原书另述的13度10分慢月界与13度10分36秒均速分别保留；“慢月等同逆行”的原文评价不写成月亮实际逆行。太阳和月亮恒顺，本项不另算助力。

没有将这些分项合成吉凶、分数或状态良好布尔值。

## 两列相位、互容与夹置

`lilly-accidental-source-v1` 逐七曜计算合、六合、刑、拱、冲，采用原书两列各星 orb 的半径和，分别记录是否进入。两列不同不择利合并，也不借用通用行运或次限产品阈值。跨座时仍保留黄经与星座几何不一致的标记。

局部接近或远离只描述当前误差与相对速度。回归星与本命点的跨图同度口径继续单独核定，整数一度格仍只用于审查。

本垣、擢升、三分、界和面互容逐项保存。双方须各自落在对方的同类尊贵内，三分使用各自盘的昼夜。原书的金星在白羊、太阳在金牛例只在昼盘成立。双子第21度的界表与正文缺口仍属未知，涉及该位置且另一侧成立时保存为待核。不同尊贵混合、是否实际救应及如何衡量综合强弱还须另验。 [第一卷印刷页112](https://krasiancientastrology.com/wp-content/uploads/2016/11/CA-I-copy.pdf#page=132)

夹制补了原文同座、目标严格位于土星与火星之间的身体夹置例。其他构形尚待核对。本命目标宫类按出生盘求取，回归宫位按该次回归地点单独计算。

## 同盘成相、换座与转逆

原书将相位正在接近、精确成相以及顺行星在成相前转逆分开讨论。针对已有几何候选的回归土星、回归金星与本命月亮，在各自盘的纪元后，追踪进入至少一列容许度、正在接近、且符合星座相位关系的星曜组合。 [第一卷印刷页107–111](https://krasiancientastrology.com/wp-content/uploads/2016/11/CA-I-copy.pdf#page=127)

计算每6小时采样一次，最长追踪32天，按1秒时间区间细化成相和换座。记录最先发生的精确成相或换座，也保留计算窗无事件和精度内无法排序的状态。相对趋近停止和原本顺行、造成趋近的一方转逆各自记录，可先后发生。32天和采样精度属于实现取值。计算窗外的事件、其他折返取法和综合有利判断继续列为缺项。

事实层 v1.236 与中文输入 v237 使用这项证据，西方规则 v67 更新三条资料的审查记录，三条仍为部分映射。合成轨迹验证成相、先换座、同刻边界和趋近停止后转逆的顺序。真实盘例覆盖客户端事实提交、服务端 SQLite 匹配和中文投影。

## 第三星先成相的三种时序

- 身体阻碍例中，较快的第三星先合原入相星，再合原较慢星，两次都在原合相之前。
- 相位阻碍例依次检查同类六合、刑、拱或冲。两次精确相位都须在原合相之前。
- 落空例中，原较慢星先与第三星合相，其后才轮到原入相星。

三式均针对原例的顺行同盘合相。计算在原合相时刻截止，各接触均须在原座内精确成立，且未先失去趋近。先后间隔须超过1秒的求根分辨率。相关时刻是盘面证据，原书关于当事人和事情的占断需要另验角色与全盘。跨座、主相位本身并非合相、其他第三星介入构形与完整制化继续逐条核对。 [第一卷印刷页110–113](https://krasiancientastrology.com/wp-content/uploads/2016/11/CA-I-copy.pdf#page=130)

真实回归例为2020年1月，水星于10日先合太阳，12日再合土星，原太阳与土星于13日合相。三时刻均以 UTC 日期标示。事实层 v1.237、中文输入 v238、西方规则 v68 承接三条资料的几何候选，条目仍为部分映射。

## 传光的先后相位

第一卷第 111 页以水星先离开火星、再与土星成相为例，合相和其他主要相位均可查。在本命月亮、回归土星和回归金星所在图层，先按两列半径的共同范围查看顺行且较快的传递星，沿同一星历向前后各查至多 32 天。分别记录各自原座内最近结束和最近将成的两个精确点。同一时刻或先后在求根精度内无法分辨时不登记传光证据。2020 年同一实算回归另见月亮离土星六合、向火星三分。角色作用及其他传光形态继续待核，时序只用于本地审计。 [第一卷第 111 页](https://krasiancientastrology.com/wp-content/uploads/2016/11/CA-I-copy.pdf#page=131)
