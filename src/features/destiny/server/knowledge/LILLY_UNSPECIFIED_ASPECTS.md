## 定义分歧与三种计算结果

《Christian Astrology》Book I印页105列六合、刑、拱、冲四种射线关系，并说明合相也常被称作相位，但这种叫法并不严格。同书Book III有未指定种类的“有相位／无相位”，也有把合相与照见分列的句子。原JSON中的`any`不自行改写为“只取四种”或“必含合相”；本次比较两种读法，只将一致结果当作证据。

| 本次已知位置 | 严格四射线读法 | 宽泛含合相读法 | 传给匹配器 |
| --- | --- | --- | --- |
| 六合、刑、拱、冲之一在本套容许度内 | 有 | 有 | 已确认有相位 |
| 五种关系均在容许度外 | 无 | 无 | 已确认无相位 |
| 仅合相在容许度内 | 无 | 有 | 未知，不生成肯定或否定 |
| 缺坐标、矛盾坐标／星座／黄道、缺宫主资料 | 无法判 | 无法判 | 未知 |
| 两个宫位角色实际由同一颗星主宰 | 无第二对象 | 无第二对象 | 未知，不自造“无相位” |

这里保留的是原书用语歧义，**并未把合相改成无相位**。明确写了合相、六合、刑、拱、冲或善相的旧条件继续用原有判据，未被本次改写。日后若逐段校勘能确定某条原文是否包含合相，应按该来源增加明确取法，不全局改写其他段落。
