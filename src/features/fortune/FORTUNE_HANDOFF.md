# 四周期运势跨模块交接

面向账户、命理、路由与集成负责人。运势已通过账户公开接口读取最近命理归档，四周期页可预览八字、紫微流限、西方行运、三术主题排序和个人建议。下列契约是交接提案，字段名由提供方和运势共同确认。变更由各目录负责人按授权实施。

YA 接入进度：指定和最近盘面均通过不可变归档 ID 读取，并按会话核对归属。新命理快照保留已确认出生时区和起运性别、顺逆、规则及 UTC 运柱边界。运势使用同一节气口径复算并对齐各运柱及边界；旧盘没有这组字段时继续逐项核对原十步大运表。报告已通过账户归档，支持历史列表与回读。独立出生档案 ID、资料版本和账户级展示偏好尚无正式契约，当前继续使用归档 ID、设备时区和周一默认值。

| 负责人 | 需要提供或确认的能力 | 最少数据与权限要求 | 验收条件 |
| --- | --- | --- | --- |
| 账户 | 按运势用途读取指定出生档案的已保存盘面 | 当前会话下稳定的 `profileId`、不可变 `snapshotId`、`timeKnown`、快照版本和各术候选。客户端提交的 ID 只用于选择，服务端按会话校验所有权。 | 本人可读。越权和会话切换被拦截。资料更新后使用新快照，旧结果仍能引用原版本。旧档案可返回明确的缺快照状态。 |
| 账户 | 展示偏好 | 可选 IANA `displayTimezone` 和周起始日。关系状态、主题偏好仅在用户自愿提供且明确用于运势时读取。 | 无偏好时使用设备 IANA 候选和周一默认值。无关系状态时使用中性表达。展示时区更新无需重排本命盘。 |

## 运势侧契约和状态

- 四周期使用同一 UTC 基准。展示窗口为半开区间，时区按 IANA 校验，周起始日默认周一。周窗口直接扫描自身交节和换日节点。
- 八字交节及晚子换日按北京时间。手动历法查询沿用子正换日，年度分析以北京时间的公历年为范围并在立春切换流年。通用黄历用北京时间当天正午查表。
- 页面接收周期窗口、节点、时钟来源和归档状态。年度报告包含区间、版本、规则 ID、证据引用和各术可用性。黄历卡单独接收 `date`、`timeZone`、`yi`、`ji`、`source`、`ruleset` 和完整性。
- 八字线索保留干支及半开区间，紫微线索保留流限宫位、大限、四化和区间，西方事件保留精确时刻、角度、顺逆行、黄经及引擎版本。三术主题保留来源编号、规则 ID 和各自的支持或留意方向。
- 个人建议按主题列出宜、忌和提运习惯，并引用未过期的事实和试用规则。规则审核可从 `control/fortune-guidance.ts` 的主题映射与行为规则表入手。紫微宫位映射、行运相位映射和试用建议均需单独确认，历史归档仍依赖账户公开契约。

## 三术计算数据与后续契约

- 入口沿用会话授权的最近档案。各术候选以各自 `rawResult` 的数组下标标识。同一下标在不同术之间没有对应承诺，紫微按时辰去重，八字和西方按 UTC 候选保留。后续若需联合候选，请命理提供候选标识及关联。计算结果沿用归档字段和独立的计算版本。
- 八字 `fortune-bazi-layers-beijing-sect2-v1` 输出交节流年和流月、北京时间 23:00 换日及两小时一时柱的完整区间、六十甲子与各日主的数据表。当前层保留十神、藏干、五行、纳音、旬空、十二长生、带本命年柱／日柱来源的流盘神煞、天干合冲与地支合冲刑害破、三合三会三刑成员。干支关系保留实体与位置，解释和化局判定另需规则。大运采用锁定库的 `getYun(gender, 2)`，输出起运分量、交运 UTC、首运前阶段及十二步大运、小运、年度和月柱表。当前归档缺少独立出生地时区及出生性别字段，因此用本命 UTC 对北京时间交节，同时保留男女两种推算；命理提供经授权的输入与确定的流派后才能选定正式起运口径。
- 紫微 `fortune-ziwei-engine-output-v1` 读回本命星盘并计算参考时刻六层运限，保留原始流限索引、干支、宫名、星曜字段、古历日期、虚岁和年曜。对宫及三方通过宫索引计算。足以指定一个 UTC 时刻时，可独立查询完整叠盘。现有周期简表仍以日周流日、月流月、年流年分别展示范围。
- 西方 `fortune-western-calculation-v2` 按 UTC 半开窗口输出精确相位及独立版本的容许度规则，数值单位为度、度／日及 AU。精确经过通过 `parentSignalId` 关联连续相位；窗口切入活跃区间时，以有界回查寻找原入相边界。出生时刻和单一归档均得到确认后才输出个人轴线和整宫。公共天象可独立计算。
- 事实服务复用账户本人归档读取接口。要满足按出生档案 ID 查询及出生资料版本追溯，账户或命理需提供经所有权校验的 `profileId`、`profileVersion` 至不可变本命盘 ID 的关联，也需明确八字起运所用出生地时区和出生性别来源。运势服务启用时，由集成配置账户 URL、数据目录和 Web 来源。

相关页面和已有入口见 [运势说明](README.md)，依赖、数据流和字段来源见 [现状审查](FORTUNE_CURRENT_STATE_AUDIT.md)。
