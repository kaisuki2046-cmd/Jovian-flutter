# 八字原局十神、透藏与固定柱位

## 原局同现与结构成立分别处理

《渊海子平》女命“原局伤官见官”和杂论“本命原有伤官见官”分别核对已确认的伤官、正官及位置。天干只取年、月、时；四支藏干均可提供十神事实，日主不额外充当天干十神。女命一条保留性别前提，七杀不能代替正官。

原有 [L2十神结构](../../control/bazi-analysis.ts) 的 `visible-or-month-main-v1` 标记要求两端各有透干或月令本气锚点。这比“原局同现”多一层门槛，本批没有拿它替代原句；新增输入直接引用原始十神位置，编译配置为 `bazi-natal-god-presence-v1`。已有采用该L2标记的来源及接口保持原口径。报告解释本次核对的是同现，不额外认定伤官格、制化成败、现实人格或关系结果。

实际排盘样例包含两神已见但L2结构未成立的情况，仍能匹配本批同现条目。若年、月、日已经给出所需正面事实，未知时辰不阻止这条已获证据的匹配；依赖时柱的具体备选不能靠未知时辰补出。缺性别、相互矛盾的性别、只见七杀或只传入结构标志均不能满足女命原句。

## 官杀与财的透藏原句

《子平举要歌》两句与《寸金搜髓论》三句分开检索：

- 官透且支藏七杀，仅引用“露官藏殺方爲福”。
- 七杀透且支藏正官，仅引用“露殺藏官是禍胎”。
- 正官透、财星藏，以及杀藏官露，各引用其对应原句，不能只见财藏就发出官清、名振乡邦等其他结论。

配置 `bazi-visible-hidden-gods-v1` 的“露”只取年、月、时天干；“藏”核对四支，正偏财分别保留。按这些记录写明的正面条件，不把“藏”自动转换成“未透”，不默补原句没有写明的缺席、取清或制化条件。不同见证可以并存，模型材料保留其并存，不强取一个单一吉凶结论。这是本批的字面条件映射口径，未把它扩大为全书所有“隐／藏”用语的统一解释。

两个原段与《子平真诠》固定柱位例使用原文、条件及来源联合指纹。任一处改变就停止旧专用编译，保留待核；不执行资料中的操作说明。分句报告只发送已满足的原句及来源，不发送未确认的整段释义或上下文。

## 明确月令与柱位

癸日甲寅时的亥、子月分支保留共同的癸日、甲寅时，以两个月为择一；“若生”没有被当成可忽略的描述。该句提示另辨取格，没有据此给出现代婚期、官职等具体结论。

时上偏财遇劫财限定时干为偏财，并有原局劫财证据；只在时支藏偏财不满足“时上”前提。语义仍未明确的其他“时柱值偏财”等记录没有一概改成时干。

《子平真诠》一条仅复现辛日、申月、年干壬、月干戊、时干丙的排列，配置 `bazi-fixed-pillar-example-v1`。不能调换年、月、时的字来满足隔伤护官，亦未据该例新增一个“所有印星都能制伤”的通用算法。原例“许贵”作为有出处的取格说明，不等于对现实身份的保证。
