# 自然表达库

把已有命理解读说成自然、具体的中文。运行时只用报告已有的主题 ID 选择可选示例。句式、节奏和词汇可以调整，含义、方向、强度和适用条件由上游解读决定。

## 接入和对照

报告服务先匹配命理书籍材料，将出处与原文、实际命中条件及现代释义组成精简文本，再把自然表达规则放到同一次 DeepSeek 请求的系统消息里。自然表达本身没有单独的 API 请求、向量索引或检索进程。

报告服务启动时读取 `DESTINY_NATURAL_EXPRESSION`。修改环境变量或 Markdown 后重启报告服务。

| 值 | 行为 |
| --- | --- |
| `rules`（默认） | 注入固定风格规则。 |
| `examples` | 注入规则，并根据报告的内部主题选择最多两段示例。主题不足时用人际或日常示例补齐。 |
| `off` | 关闭风格注入和文风提示，便于对照。 |

文风规则和启用的示例用于提示词。生产报告直接返回模型正文。文风检查函数保留供独立评估使用。

风格规则及可选示例会增加输入字符，具体长度随文档内容变化。未用真实 DeepSeek 请求测量计费 token。

本地验证使用 `node scripts/test.mjs src/features/destiny`。离线测试覆盖消息结构、示例格式与注入上限、文风提示。真实模型的改写自然度与含义保持仍需人工对照评估。
