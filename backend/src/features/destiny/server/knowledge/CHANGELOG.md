- 旧版 3,095 条规则与新版 18,846 条 Claim 合并为 `destiny-knowledge.sqlite`，统一目录共 21,941 条，保留原始出处、条件、来源和接入状态。

- 三套 Claim 共 18,846 条及其 79,664 个完整或分句条件组迁入 `natal-claims.sqlite`，保留 JSON 作为审查与重建资料源。
