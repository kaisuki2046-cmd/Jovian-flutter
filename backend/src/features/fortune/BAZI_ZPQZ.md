# 《子平真诠评注》透藏与会合计算

十三条月令禄刃、甲酉辛官及高命火运资料另用[月令与透藏](BAZI_ZPQZ_MONTH.md)：月建逢禄不被藏比肩替代，甲酉条件不省略，原文相反评语分开保存。

另有八条干支、根位、冲会资料使用[逐柱冲会计算](BAZI_ZPQZ_MOVING.md)，分别核原局数量、岁运同柱并冲、半会与完整成员；不改变本文四条透藏与会合的来源取法。

十条涉及财印相并相隔、运合官杀食伤的资料另用[天干柱序与实际对象](BAZI_ZPQZ_STEMS.md)，日干自身留在柱序，其他透干与大运目标分别核定。

本批对应卷四 p043、p044、p054、p055 四条解读，源 JSON 保留不改。新增 `control/bazi-zpqz.ts`，按同一候选本命与同一步实际大运生成 `zpqz_luck_context`，规则仍由 SQLite 读取。四条由原来的分离条件查询转为一条带本命和运段的来源上下文，避免把不同候选的条件拼合。

## 来源与取义

来源为 [NCC 卷四转录](https://www.ncc.com.tw/fate/paleo/bg/bg_034.htm) 的第二十六、二十八章，保留沈氏正文与徐乐吾评注的归属。该网页是数字转录，本批没有宣称核过1936原刊影印。原 JSON 的完整上下文、出处、条件及审查哈希保留。

原文要求十年并论，又在特定透清、会合段提到五年效用；尚不能据此一律划为干前五年、支后五年。因此实际十年大运只是结构背景，不代替五年作用的起止；没有把待核效用铺满十年，也没有新增未核定的五年切点。

## 计算字段

- 每条藏干保存本命柱位、地支、十神及引擎藏干序号；原局非日干处已透、与日干同干及运干同干分别核验。出生时刻未知时不使用时柱，也不能断定全局未透或本运首次透清。
- 根位分别注明藏同一干、只藏同五行异干；沿用已声明的同五行藏气口径，数量不作为强弱分数。本章直接列明的亥壬禄、亥甲长生、寅甲当旺/丙方生/戊寄生、辰戊本气/乙春余/癸水墓单列，未明支位不推造同源全表。
- 与运柱的六合、六冲等关系保存参与柱位及完整干支。申酉对寅卯的具体冲位可查，不据此认定已经冲去、阻止会局或完成救应。
- 三合、三会分别列出每一支的本命柱位、是否由大运提供和缺失成员；重复亥不当作另一支，原局已齐与本运补齐分开。成员齐全不等于已合化。
- p044 候选明确限定壬日亥月透己、未运、亥卯未缺卯及未中己本气。有卯而成员全齐的盘不再套“亥未虚会”候选；这仍不足以断定虚实程度、官星得用或格变结果。

## 本命和大运的干支配对

`p055` 查询要求四柱与档案出生时钟一致及唯一大运已核。四柱分别查本命干到运支、运干到本命支，并记录查到同干、只见异干同五行或查无该根的结果。也逐一登记本命与运支藏干在原局和当步运干的实位。寅、亥藏甲，卯、未藏乙，这四支按本章所列口径单独记录为甲根。四寅原图逢午和施再村原图另有来源对照。此条完整落实逐干支配对，原文取壬、取甲或兼取为解读前提。 [NCC 卷四第二十八章](https://www.ncc.com.tw/fate/paleo/bg/bg_034.htm)

对参与跨层配对的每个亥位，分别记录实际出现的壬、甲及其天干柱位，保留壬禄、甲长生的出处。日干可以参加配对，透出的记录沿用非日干位置。沈氏并见时的取用和徐氏对藏气次序的评注保留为不同判据，实际发用仍待核。1990 年 11 月 13 日北京时间 18 时样本在 2012 年由乙酉转甲申，乙酉阶段无符合本条的跨层配对，甲申段从实际交运点起可部分匹配。

沈氏并透兼用与徐氏对藏气次序的评注分歧保留。没有把藏干表顺序替代气势轻重，也未把十神、根位、会合结构直接判断为格局或喜忌。四条仍为部分映射；当前全库覆盖见[条件映射进度](CONDITION_MAPPING_PROGRESS.md)，不以本批历史统计表示现状。

### 寅辰藏气次序与实际见干

`p055` 将徐注所列寅的甲、丙、戊和辰的戊、乙、癸顺序绑到实际参与跨层配对的支位。逐字记原局年、月、日、时天干和当步运干的实际落点。1970 年戊寅运样本按实际运支寅记录时干甲、日干丙和运干戊。1983 年乙亥运样本由运干乙在日柱戊辰得根，辰位另核月日两戊和时干癸。该段只将日柱戊辰列为参与配对的寅辰根位。评注对取用的限制及五年作用起止仍待核。 [《子平真诠评注》卷四第二十八章](https://dao.time.actor/ziping-zhenquan-pingzhu/juan-4)

### 四寅与施再村两幅原图

### 午会的柱位与辛官庚杀

`p054` 逐柱核对本命午和实际寅运或戌运。原文以年午较重、日午次之、时午较缓，按各自位置保留。参照上一章的具名示例，甲日逐查原局酉支与实际透辛、申支与实际透庚。午与透干分居两柱时，保留实际午中丁火所克的正官、七杀端点。寅午戌的实际成员及缺支单独保存。成局、实际制煞或伤官及五年作用起止仍待核。 [《子平真诠评注》卷四第二十七、二十八章](https://dao.time.actor/ziping-zhenquan-pingzhu/juan-4)

2020 年庚寅运样本分列年午和时午，只有年午与时干庚构成别柱端点。1973 年戊戌运样本的时午会运戌，原局年干透辛正官。2014 年甲戌运的寅月样本在年柱庚申核得庚杀支位，时午与年干庚构成别柱端点。另有仅庚午同柱、酉月只透庚、申月不透庚的盘例，仍保存实际会位，均无具名克向端点。

### 月令与别支的藏干新透

## 壬日亥月的会局与回冲

同一候选须为壬日、月支亥并有非日干己透。p043 按徐注分别登记寅运六合本命月亥、卯运与月亥会位。卯运保留缺未、运补齐和原局已齐等成员情况。正文的未运另查是否补齐此前缺未的亥卯未。补齐证据须来自原局与实际未运。 [〈论行运成格变格〉](https://dao.time.actor/ziping-zhenquan-pingzhu/juan-4)

有本命申冲实际运寅、或本命酉冲实际运卯时，SQLite 将该运段归入 p047 的对应回冲候选。对应冲位的检查在两个事实投影共用同一支位取法。申遇运卯、酉遇运寅，或流年申逢运寅，均以当前大运及原局的实际配对为准。p044 以及 p047 的未运虚会分支都要求原局缺卯。p047 另有原局申或酉的前提。未运补齐时进入 p043 的正文分支。

完整出生资料的盘例覆盖真实交寅运时刻、两种对应回冲、流年只供冲位或会位，以及未运补齐、缺卯和原局本已齐备。三条维持部分映射。己官是否为用、实际合化、回冲是否阻止变格、五年作用起止继续待核。事实 v1.215、八字规则 v60、中文输入 v216。

### 壬禄、己官根位和会位所藏甲乙

`p043` 逐柱绑定本命月亥的壬禄、原局明透己官所在位置及当步会合涉及的实际藏气。寅亥六合只核月亥、运寅参与的甲木，两支所藏甲按壬日为食神。卯运及未运另查亥卯未的实际成员，卯、未所藏乙按壬日为伤官。只列参与会位的甲、乙对已核己官的五行克向。 [〈论行运成格变格〉](https://dao.time.actor/ziping-zhenquan-pingzhu/juan-4)

`p044` 的亥未缺卯分支逐柱列原局己官的同干根位，并查当步未中己为本气。未中乙伤官独立留证，运干乙与运支己各记所在。`p047` 的未运分支共用该事实，仍须见原局申或酉。回冲分支则查本命申庚偏印与运寅甲食神、或本命酉辛正印与运卯乙伤官，同一对保存六冲和藏干克向。

完整盘在 2011 年乙未运验证原局无己根与时丑已有己根两种情形。另验证仅原局其他支藏甲、原局无明透己、两种实际回冲、原局木组已齐及交运切点。实际取用、成化、回冲作用及五年起止仍待核。事实 v1.295、八字规则 v119、中文输入 v296。

## 印食透藏与护官补算

十四条改用同候选、同实际运段的印食透藏事实。十一原图保留柱序与录文疑点；明透与支藏、柱间对象和根位分开，李例癸运核实际戊食目标，马例核原局与运支成员。毛例隐藏食财不能被“不见”抹去，某富翁子年月干配不一致不修源。来源轻重、护官和合化仍未知，十四条仍部分。详见[印食透藏与护官](BAZI_ZPQZ_SEAL_FOOD.md)。

## 偏官伤官取运与取清对象
