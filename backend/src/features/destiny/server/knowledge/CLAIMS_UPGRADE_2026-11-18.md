## 算法和匹配

随后完成 SQLite 运行库改造，并与旧版 3,095 条规则合并到 `.local/interpretations/destiny-knowledge.sqlite`。统一目录共 21,970 条，当前保留 Claim 的 18,875 条源记录及 93,525 个条件组（含命例），重复条件去重为 91,056 个规则。JSON 继续作为可审查资料源，报告、库存、解释和映射审计从统一 SQLite 查询。原分库文件不再参与运行查询。构建、自动更新与回滚约定见 [知识库说明](README.md#json-资料源与-sqlite-运行库)。运行库迁移与后续算法接入分别记录在进度中。第十九批升级至 schema 4，在同一文件增加240个托勒密界表计算单元。全库计算参考源为 402 条（莉莉尊贵表 144、莉莉庙座栏标与擢升度 21、莉莉强弱表 41、托勒密界表 160、托勒密分类 19、莉莉相位 17）；原界表与尊贵表的400个单元保留，另有61个分类条件单元存于同一SQLite元数据，不混入个人整条或分句索引数；查询与来源边界见 [三套界表](PTOLEMY_TERMS.md)。

- 八字读取 `destiny-experience-v1` 中可执行的本命条件。当前 135 条 `ready` 一般规则中，134 条进入整条索引，1 条按原文分句接入。另有 19 条 `ready` 命例，18 条可按完整四柱及原例要求的性别对照，1 条胎元待核。另有 2 条《子平真诠》底本异文命例经馆藏本校对后接入。命例索引以 `case_indexed` 标识，报告可引用四柱和出处。
- 西占的 156 条商人命例按 1647 年初版第 742 页七曜及十二宫头的角分对照，使用同一 `case_indexed` 状态。印盘、表格及正文的出处分别随证据返回。 [印盘与表格](WESTERN_INTEGRATION_RESEARCH.md#第一百六十一批莉莉英格兰商人印盘与表格对照) · [各宫正文与核对](WESTERN_INTEGRATION_RESEARCH.md#第一百六十二批莉莉英格兰商人命例后续章节) · [末章取材与派生图选星](WESTERN_INTEGRATION_RESEARCH.md#第一百六十三批莉莉商人命例与父母派生图选星)
- 紫微支持新版「本命某宫某星」、同宫、庙旺陷、独守、指定宫支和生年天干表达。旧版组合段落拆成新记录时，每个 ID 独立匹配。例如 `ziwei-v2-caibogong-p101007-001` 仅核对天同守财帛；`-002` 另核对天同与巨门同宫。异宫巨门不能满足同宫条件。
- 独守仍要求完整星表所确认的正曜或核心星数量，不能仅凭传入一颗星便认定。明确无煞也需要对应宫位的完整星表作证，缺失信息不等同于不存在。
- 西占新增下降点、宫头星座和行星顺逆行事实。顺逆行由现有天文引擎在出生时刻前后半小时的热带黄经差计算，处理跨 0°；随结果提供每日速度。默认展示宫制保持整宫制，专用历史判读见后续批次。新增字段兼容没有 `motion` 的旧盘面。
- 西占条件别名 `asc`、`desc` 接入既有角点。`include` 为组间或、组内且；`exclude` 同样为组间或、组内且，任何排除组命中都不采用该条。只有同一星体、角点或宫位有唯一确定值时，才能证明其其他值不成立。
- 出生时间未知时，客户端与服务端都不采用宫头、角点、宫位、昼夜和既有运限事实；行星事实仍须经过候选时刻的稳定性筛选。
- 旧 ID 的四个文字条件或原文修订后，未通过新版完整条件编译的旧人工分句停止使用，避免同一 ID 已改含义却继续引用旧映射。修订 ID 保存在导入清单，审计逐条标注。
- 兼容 HTTPS 出处及提供的相对路径资料出处，保留本地来源但不访问或执行其路径。证据上下文兼容字符串、空值及含 `sections` 的对象。模型只接收当前命中记录原文或已命中分句，不接收完整上下文，也不接收机器匹配配置，避免带入未命中断语及冗余章节。

```powershell
node --experimental-strip-types src/features/destiny/server/knowledge/claims-upgrade-audit.mjs
```
