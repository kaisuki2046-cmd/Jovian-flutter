# 西方次限推运计算与映射

本轮基线 `7154255`。目标仍是剩余资料逐条建立条件映射并补足计算事实，当前没有完成全部条件。修改限运势目录，无公共 UI 或其他业务改动。

## 实现与范围

`control/western-progressions.ts` 核验兼容的 `astronomy-engine` 本命快照、已确认时刻及单一候选。出生时刻优先取西方原始儒略日；只有八字来源引擎和版本兼容时才允许以其归档 UTC 作回退或交叉核对。两个时钟不一致、时刻未知、多候选、缺少时间、本命黄经与星历不符时，不产生确定的次限事实。已有行运仍保留，新增缺项明确记录为部分可用。

日代年采用 UTC 原出生年月日时锚点，整年等于一个星历日、整月等于两小时；月内按相邻月锚点实际时长连续插值。目标月没有原出生日时夹至月末，保留可逆计时函数。此插值及闰日处理是明确的产品实现，不声称原书给过现代闰日细则。

通用产品计算器继续计算十天体的次限位置对本命位置，区分黄经九种相位（0、30、45、60、90、120、135、150、180 度）及同向赤纬平行。黄经使用视地心当日热带黄道；赤纬统一至本命时刻的真赤道参考系，避免跨历元比较不同赤道。平行要求同向，不以反平行、绝对赤纬相等或黄经合相替代。

通用黄经 1° 与同向平行 0.25° 为产品判定阈值，不冒称 Leo 对全部相位给过统一容许度。查询窗口最多 368 天，最多每两实际日采样，先找停驻极值，再求阈值和精确点；因此不能只因样本两端都不满足而漏过中间短暂进入的区间。根定位精度为实际时间一秒。窗口内有效部分、完整成相点、是否被窗口截断分别记录，不声称窗口边缘就是完整行运事件的起讫。

Leo原书计算页另明确赤纬绝对值一度范围，不要求南北同向。独立来源事实已据此补入，31条含平行的机器条件记录与源JSON的同向文字冲突；通用扫描规则保留。294条来源相位另含双方本命星座、可用的Placidus宫位和相关月亮区间。详见 [Leo来源上下文](LEO_SOURCE_CONTEXT.md)。

## 接线与自然语言

事实层新增 `progressed` 层级及 `progressed_position`、`progressed_aspect`、`progressed_aspect_exact`，保留原始星历依据和精确点时刻。位置事实明确为参考时刻的样本，不当成整个年窗保持同一度数。西方实现引入时事实层版本为 `fortune-calculation-fact-layer-v1.3`，当前来源事实补齐后为 `fortune-calculation-fact-layer-v1.24`，策略进入计算缓存哈希。

模型上下文保留原有完整命中事实优先，并在每方法既有 24 条容量内为次限事实留位。真正发送前全部转为中文，说明次限相位的目标层、坐标、容许度、窗口截断及尚未核实的本命或触发条件。内部字段及出生时间留在本地，来源条件完整满足后才能发送对应的原文及现代释义。当前提示词版本由 `control/fortune-prompt.mjs` 的 `fortunePromptVersion` 统一声明。

十一条月亮过宫使用 `leo_lunar_house_context`，在同一时段分别核对次限对本命和对同图次限的相位。第一宫另用 `leo_lunar_ascendant_crossing` 核对穿越上升宫头的时刻。第一、第三宫均有年度次限宫条件。模型优先保留相关的穿越时刻与过宫背景，全部区间和索引供本地审计。十二条仍为部分映射。见[月亮过宫说明](LEO_LUNAR_HOUSES.md)。

## 原始依据与验证

核读 [Leo 原书第 VII 章](https://www.astro.nu/wp-content/uploads/The-Progressed-Horoscope-Alan-Leo.pdf#page=52) 的生日及半年计时示例，并核对第 XI、XII 章对本命方向和太阳、月亮呼应的区别。星历坐标使用 [Astronomy Engine 官方文档](https://github.com/cosinekitty/astronomy/tree/master/source/js#geovectorbody-date-aberration--vector) 的地心向量与赤道旋转接口，实际依赖仍为仓库锁定的 2.1.19。

`western-progressions.test.mjs` 验证原书生日/半年时标、闰日及逆换算、时钟冲突、不兼容时钟拒绝回退、本命一致性、极值两侧窄区间、反平行拒绝、真实星历与太阳弧/实际行运区别、342 条查询的分族与方向，以及事实进入中文 Prompt 而未完成来源不进入命中区。原法角度与来源宫界另已实现，验证见 [来源宫位说明](WESTERN_HOUSES.md)。独立Leo原表、异向一度示例、赤道过零、本命背景和月亮交集另由 `leo-source-context.test.mjs` 验证。完整覆盖仍须继续增加本命、宫主及逐条分支的算法与正反例，不能用这些基础测试代表全部资料已走通。
