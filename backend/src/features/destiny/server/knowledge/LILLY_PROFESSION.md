# 莉莉职业指征：前两步接线

第20批把职业断语所依赖的选星步骤接到实际查询。范围是《Christian Astrology》卷三 p.625 的前两步，不代表后续月亮相位、强弱比较及日先升步骤已经实现。计算配置为 `lilly-1647-profession-first-two-v1`，实现见 [选星计算](lilly-profession.mjs)，来源与新增输入见 [清单](claims/integration-batch-20-20261118.json)。

## 来源和计算边界

提供库中 `profession-method-p001`、`p002`、`p013`、`p014`、`p015` 的必要条件分别保留，不修改这些原始 JSON 记录。对照原书的 [卷三公开录文 p.625（PDF 第139页）](https://www.worldastrology.net/wp-content/uploads/2008/12/CA-III.pdf#page=139) 和 [卷一 p.113（PDF 第133页）](https://www.worldastrology.net/wp-content/uploads/2008/12/CA-I.pdf#page=133)。公开录文题页同时有第二版与1647字样，本批据其与提供库共同明确的前两步核对逻辑，没有据此宣称完成初版影印逐字校勘，也没有把 p.626 的另一选星说混入 p.625。

第一步分别检查水星、金星、火星：按莉莉黄经及宫头前五度规则判入第一、七或十宫，至少具有一项本质尊贵，并满足离太阳至少17度。原书允许多颗同时合格，均为职业指征，不用评分强选一颗。太阳距离取黄经最短弧，完整17度为边界；日心17角分的强化说明没有被添加为 p.625 日光距离条件的例外。同星座燃烧范围小于日光范围，本步骤的17度条件同时排除了燃烧；这里不另行给所有行星输出一个通用燃烧状态。

本配置返回初始选星的成员与唯一状态，不是全书最终职业裁断。p.626 下一章另有强力相位引起的性质混合及水星向火星移交，强力判据尚未自动化，不能把本配置的“唯一”扩大解释成最终只由一星决定。p.627 水木职业条目在提供库的1647摘录为合相或成相，公开录文仅写合相；本批保留提供库已核的备选，不据现代录文删掉四种相位。

仅在三颗星各自的第一步条件都已证实不成立后，才进入第二步：十宫星座的传统庙主须为这三颗之一，具有本质尊贵，并且不落陷。第二步没有另加第一步的落宫和日光距离限制。若仍不符合，后续第三至第五步保留待定，不能输出“三颗都不是职业主星”。

落宫使用 [莉莉宫位计算](../../control/lilly-houses.mjs)，不借默认整宫制或三维几何落宫。尊贵通过统一 SQLite 中既有的1659 p.104固定表计算，庙、擢升、昼夜三分、界和面均可提供本质尊贵；沿用独立的 [尊贵表配置及来源](LILLY_DIGNITIES.md)，不混用托勒密的三套界表。第二步的“不落陷”另行确认，不能凭有其他尊贵忽略它。

## 不完整资料和唯一主星

每颗第一步候选按已知真、已知假、未知处理；任一必要条件已假即可排除该候选，但缺资料本身不是假。只要有已确认候选，就能返回其成员身份；其他候选未查全时，不能宣布它是唯一指征。两颗以上确认同主时，三颗的“唯一”均不成立。

未知昼夜分别执行完整的昼、夜选星流程，最后仅保留两条流程一致的成员／唯一事实，不把两个昼夜分支的中间条件拼接。互相矛盾的昼夜声明不生成选星事实。缺宫头、冲突黄经、星座与黄经不一致、缺源表或未知时辰不能靠外部传入的历史标志补证；请求中的 `western_lilly_` 事实及反证都在运行时删除并重算。

## 第一百二十批·莉莉职业篇的混合指征与月亮入相

职业主星继续按卷三第 625 页的前两步确定。水星与土、火星的原句允许合相或四种射线相位。土星照水星或金星句要求两颗均为职业指征，分别查土星至少照见其中一颗。涉及木星或土星同时参与两个指征的句子，分别查实际相位，两组关系必须符合同一套容许度。木星与水星、火星的善相取六合或三合，紧张相取刑或冲。 [卷三第 627–631 页录文](https://libraryofagartha.com/Occultism/%27Aryan%27%20Occultism/Astrology/astrology%20books/William-Lilly-Christian-Astrology-1647-volume-3.pdf#page=141)

四条月亮分句核对月亮所在星座与当下朝向水星的同一合相、六合或三合。用实际黄经、时速度和莉莉容许度判方向，刑冲或离相不能补足入相。第 630 页的歌唱分句另查水星、金星均为职业指征、实在同一座合相，水星有明确的逆行证据。记录保留日火的三种来源语境，区分同现或友好相位、刑冲，以及第 633 页单列的太阳照见火星。 [卷三第 628–633 页录文](https://libraryofagartha.com/Occultism/%27Aryan%27%20Occultism/Astrology/astrology%20books/William-Lilly-Christian-Astrology-1647-volume-3.pdf#page=142)

28 份原生盘覆盖 22 条资料的 56 个条件组，逐项验证 SQLite、逐条解释和报告取材。报告保留实际命中的合取关系及容许度，多个分组同时满足时也保留各自的相位证据。古书中强力相位导致职业指征移交、太阳合相相关尊贵口径及木星同宫时的职业参与条件继续待校。 [原生盘例](claims/integration-batch-120-witnesses.json) · [回归测试](integration-batch-120.test.mjs)

## 第一百二十一批·莉莉职业选星的前三步与日水合相

第一步记录确实入选的水星、金星和火星，可多颗并存。三颗都已明确排除时才进入第二步，由实际十宫主的本质尊贵及落陷状态决定是否入选。游离与落陷按各自的事实保留为拒绝第二步资格的依据。原有职业指征和独主事实继续表达前两步的结果。 [卷三第 625 页录文](https://www.worldastrology.net/wp-content/uploads/2008/12/CA-III.pdf#page=139)

前两步都有排除依据后，第三步才取与月亮成对应整度六合、刑、三合或冲的候选。只有三颗候选星的黄经均已确认且仅一颗符合，才输出第三步的唯一候选。有两颗以上实际照月时给出比较提示，原书的强度、相位品质、精确程度和左相优先留给后续裁断。第四、第五步各保留待核备选。 [卷一第 106 页录文](https://www.worldastrology.net/wp-content/uploads/2008/12/CA-I.pdf#page=126) · [卷三第 625 页录文](https://www.worldastrology.net/wp-content/uploads/2008/12/CA-III.pdf#page=139)
