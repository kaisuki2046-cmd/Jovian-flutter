## 职责与边界

Agreement System 负责协议正文、版本、用户确认及授权撤回要求；Moderation System 独立管理内容审核相关职责，目前暂缓。账户继续负责身份与账户数据，业务模块负责业务计算与结果。

未来实现沿用 model、view、control、requests；服务端和持久化留在所属模块。跨模块只使用明确开放的入口，不读其他模块内部存储。公共 UI 按根协议共建，但本次不涉及 UI。

## 开工与交付

先检查分支、基线、工作区和暂存区；保留同树聊天和其他人的改动。协议中的待确认项未解决前不得标为正式发布，不得把文档要求写成已实现功能。

文档任务检查链接、状态、事实与授权范围；代码任务另行运行相应检查。显式暂存本轮文件，禁止 `git add .`、`git add -A`、`git commit -a`。提交、合并、推送按用户授权执行。
