# 合盘跨板块接线交接单

**临时文档。下列事项完成并通过联调验收后，请删除本文件，并移除合盘 README 中指向本文件的链接。**

## 路由负责人 · 本期

底栏入口已连接 `SynastryScreen` 和命理公开的 A、B 方手填编辑器。访客可手动录入双方资料，会员仍可选择本人归档。

验收时从底栏打开正式合盘页。分别以访客和会员身份确认获准使用 B 方资料后打开编辑器，授权合盘 AI 数据共享后可以比较并查看四类关系报告。访客只能看到本次游客会话中保存的报告，会员可读取本人归档快照。撤回本次 B 方确认会清除页面里的 B 方盘面和报告。旧归档缺少结构化盘面时，会员可回到命理重算。

## 命理负责人 · 双方手填及版本信息

A、B 方编辑器共用必填和时区校验。手填完成后只返回三术盘面投影和计算时间。含未知出生时间的旧归档仍需补齐后重算。

可持久化版本另需明确的快照 ID、标准化输入哈希、时间精度、采样和计算配置版本。由命理在计算时生成，并与账户协商保存结构。

宫干飞化已接入命理手填和新归档。合盘按账户公开的可选紫微字段消费宫干信息并校验各落点。

- 命理使用 iztro 的宫干和四化映射，校验各星曜在原盘均有唯一落点，再输出禄、权、科、忌四项 `{ marker, star }`。
- 账户校验并投影可选的 `heavenlyStem` 和 `stemTransformations`。旧归档仍可使用三方四正等事实，缺少飞化数据时页面会提示。
- 验收用两份完整盘检验双方方向、发起宫干、四化星曜、本盘落点、对方同支宫位、自化落点及同支对照。另以两份旧投影确认三方四正可算、飞化提示缺数据。排盘口径变化时同步验证双方版本兼容。

## 账户及服务集成负责人 · 后续

本人归档复用 `requestLatestSynastrySnapshot`，有稳定 `snapshotId` 时可通过公开的 `requestSynastrySnapshot` 定位。现有接口只支持本人。邀请、选择已获授权的 B 方快照和持久化报告，需要账户负责人提供公开的会话绑定、快照选择、授权查询及归档契约。先确认受邀人是否必须注册、数据保存与删除期限、授权撤回的行为。邀请须使用不可预测的短期令牌，具备范围、使用状态及撤销校验，地址中只放令牌。验收覆盖未授权读取、重复提交、过期和撤回。

当前解读入口为 `POST /synastry/summary`。客户端提交双人比较事实，服务端用 SQLite 直接匹配独立资料条目，再按四类关系分配和筛选。发给 DeepSeek 的材料包含命中条目的原文、现代解读、原文命中条件、作用方向和内容类型。系统指令要求以命中条件说明依据，以现代解读为准写结论。页面呈现四段正文并通过账户接口归档，沿用现有 JSON 响应。变更供应商、日志保留策略或传输字段时，仍需核对授权范围。
