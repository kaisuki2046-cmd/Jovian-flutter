# 《全书》限运来源事实

运势模块为《全书》资料逐条补入来源计算和查询。最初一批 11 条旧资料原无查询，接入时 1 条完整、10 条部分匹配。当前紫微全库覆盖见[条件映射进度](CONDITION_MAPPING_PROGRESS.md)。紫微雲资料的发干、日界及闰月口径沿用各自的来源复核。

## 明刊火铃在岁限和斗君月的用法

## 独立表与兼容原盘

四条羊、罗网及强弱资料另用[主曜与本生忌候选](ZIWEI_YANG_TABOOS.md)：本段羊庙陷、主曜明确格和宫名强弱两表分开；未年忌支的歌句/注文差异不择利，实际年限对宫不当完整忌法。

三条白虎资料另用[年度四飞星与岁限分层](ZIWEI_TIGER_LAYERS.md)：年度白虎、太岁和本命产品白虎分别定位，太阴问答的明列支位不被卷三通用亮度替换；不强加未明同宫范围。

四条天马资料另用[本生年空亡与马位](ZIWEI_HORSE_VOIDS.md)：截路、旬空双宫与古天空分开，动态流昌不借本命文昌替代；本命马和当前年度重用候选分别保留。

六条身命、刑忌及七杀资料另补[身命与同段岁限](ZIWEI_BODY_LIMITS.md)：身宫按同卷生月生时独立核位，大小限与身、命分别列关系；本命源四化和年度延用候选分开，未据位置宣布救应生效。

计算位于 `control/ziwei-quanshu.ts`。取法补读[卷二安身命、安禄存、羊陀及四化口诀](https://zh.wikisource.org/wiki/紫微斗數全書/卷二)和[卷三羊陀迭并、限运与明列亮度](https://zh.wikisource.org/wiki/紫微斗數全書/卷三)。源 JSON 的固定修订 URL、原文、条件和解释保持原样；补读链接是支撑算法的录文，不声称已比对固定修订的全部全文。

- 禄存按十干的明列地支计算，擎羊在禄前一宫、陀罗在后一宫。庚为申禄、酉羊、未陀，癸为子禄、丑羊、亥陀；不混用羊陀互置的异文。
- 四化使用录文十干表，壬干为天梁禄、紫微权、**天府科**、武曲忌。与默认表的壬干左辅科、令东来庚干双忌独立，不改它们的算法或配置。
- 亮度只录卷三明确的星、支、等级。文昌卯、紫微辰等未列单元保持未知，不由引擎亮度填满。七杀在巳亥按表为平；其他章节的“陷地”等分支仍须核其含义，不能凭单表抹去分歧。
- 主星及一般星曜位置复用兼容公开快照，源表亮度和生年四化另算。这不是把整套《全书》本命星盘全部重排。辅弼昌曲已另按生月、生时独立重算；魁钺按录文作无序支位组，丙丁猪狗保留亥戌，不擅自给两个支位分配单星名称，见[辅助星说明](ZIWEI_SUPPORT.md)。火铃原文宫位组与产品生时法的差异已分别记录，但原法生时取法仍须核，见[火铃复核](ZIWEI_FIREBELL.md)；古天空另按生时独立核位，见[空劫说明](ZIWEI_KONGJIE.md)。

确定本命依据先检查十二宫索引、地支唯一和结构，按本生月与生时重算命宫，再核迁移对宫。生年干须和农历出生年一致，禄羊陀还须与归档的唯一实际位置逐项一致。错位、缺星、重名位置、错命宫或缺依据不产出确定来源事实。本轮未重建闰月来源本命盘；闰月明确不可用，不静默套默认半月法。

## 逐条覆盖

全部 11 条均保留来源段号、证据与条件 SHA-256、已映射事项和具体剩余条件，运行时从 SQLite 读取。庚例要求庚生、命卯、迁酉、本命酉羊、流年也是庚、年禄申羊酉陀未，且归档和来源重算一致，故本条可完整匹配；与所用版本相冲的记录不可适用。

其他 10 条仍缺原文所未定或尚未核全的前提，例如“大限将出”的提前量、“吉众”的数量、文昌或魁钺“遇”的同宫/夹/冲/会范围、化禄权科忌的发干层级、月日时的来源排法及吉援解救。已经有真实宫位或查到生年科不代表这些条件已成立。对应查询是部分候选，未作为完整命中提供给模型。

### 明刊日月化忌的缓和见位

第 285 条的明刊日月分支按生年甲干太阳忌守寅卯辰巳午，或生年乙干太阴忌守酉戌亥子。由大限实守，或由已按原法重算的小限实守。其他发干的日月见位保留为比较证据。天同、巨门仍按明刊所列生年条件查询。实际命例验收四种真守、太阳酉及太阴申的异宫、仅其他发干符合与小限错位等反例。其他煞曜组合的取法仍待核。 [明刊化忌入限原段](https://sndmp.com/classics/facsimile/quanshu/book-1/0126.jpg)

两条明列处所的日月例外各自确认。只有公历、农历生日以及五行局复算的紫微位置与归档星序相符，甲年太阳化忌或乙年太阴化忌的实际守限才可使用相应短引。整组星位与同月异日的出生档不符时，即使旧限位候选可用，也仍待核。解读仅引用这两处日月例外，不带同段其他化曜或煞曜的说法。 [三卷本卷二〈化忌〉](https://zh.wikisource.org/zh-hant/紫微斗數全書/卷二#一_命宮)

## 天刑二限与入庙例外

扩充条 `career-quanshu-interpretation-expansion-p018-001` 的原短引为二限遇天刑，并有入庙转吉的例外。[卷一固定修订7913704的同篇歌诀](https://zh.wikisource.org/w/index.php?oldid=7913704&title=紫微斗數全書/卷一#問天刑星所主若何？)列出寅、酉、戌、卯；本条明确将这四支解释为入庙例外的定位。这是该段的阅读口径，不是把卷三亮度表增补成所有篇章通用的天刑等级；四支外仅记“未列”，不能据此标成落陷。

[卷二固定修订1963110的安天刑天姚诀](https://zh.wikisource.org/w/index.php?oldid=1963110&title=紫微斗數全書/卷二)从酉起正月顺数生月。新增函数从农历生月独立重算天刑，要求与归档中唯一位置相同，随后在当前大限或小限命宫核相逢，分别保留入庙支位内和未列支位的条件。缺星、重星、位置不符或原盘依据不完整不产出确定条件；闰月盘继续明确不可用，不套默认闰月分半。

“二限”按本条原意覆盖大限或小限，不额外要求两者同到。限层采用已声明的产品农历新年和虚岁口径，不声称复原全书所有篇章的起限法。生年天刑不代换成流天刑，也不用流月、流日或三方任一星位代替本限相逢。入庙例外与未列分支同时可匹配，不能只筛入庙正例后称全条完成。

本条完整是指短引的二限相逢及入庙例外均有可计算条件。相邻歌诀的昌曲吉星来凑合、文星成就、天哭同到并未被本事实认定；它们不在短引的入庙定位之内，不能因本条命中而声称这些增强、加重或现实事件已经成立。原 JSON 的全文、条件和现代释义保持不变，机器规则保存原源证据哈希、补读固定版本链接和这一具体取法。
