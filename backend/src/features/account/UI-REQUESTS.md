## UI-ACCOUNT-01 分段选择

- 申请板块：账户；状态：待共建与接入。
- 页面及临时代码：auth/view/components/AuthSwitch.tsx 的 AuthSwitch，以及 view/VisibilityChoice.tsx 的公开与保密选择外观。
- 现有缺口：公共 UI 尚无分段选择组件。AuthSwitch 已从登录页拆出，易于替换。
- 需要的能力：选项、选中值、切换回调、禁用、可访问名称与选中状态；支持不同长度文字。
- 使用示例：登录/注册、验证码/密码、公开/保密。
- 验收条件：选中态清楚；禁用无回调；窄屏可读；键盘与触摸可操作。
- 业务侧负责：选项文案、何时显示、当前值、请求期间禁用、切换后的字段和校验、可见性保存；这些继续留在账户。
- UI 交付需提供：组件名称、导入路径、调用示例、支持状态、已有调用方影响、交付提交与合入版本。
- 接入回执：未替换；跨目录接线：无；当前实际操作继续使用临时组件。

## UI-ACCOUNT-02 密码输入外观

- 申请板块：账户；状态：待共建与接入。
- 页面及临时代码：view/form.tsx 的 Field 密码显隐部分，登录、注册和安全页共用。
- 现有缺口：公共 Input 已支持字段与错误外观，密码显隐图标和布局目前由账户补充。
- 需要的能力：优先扩展 Input；支持显隐、禁用、错误、自动填充和文字输入事件，密码文本不得被日志记录。

- 验收条件：多次进出焦点后仍可切换；切换不丢文字；禁用时不可操作；图标有可访问标签，输入文字不被遮挡。
- 业务侧负责：密码值、长度与一致性校验、输入类型及提交操作；密码要求仍由账户控制。
- UI 交付需提供：参数及兼容默认值、导入路径、例子、支持状态、现有调用方影响、交付与合入版本。
- 接入回执：未替换；跨目录接线：无。
