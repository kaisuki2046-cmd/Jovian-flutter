# 合盘读取账户命盘快照

状态：待账户与命理负责人确认的接口需求。合盘通过账户公开接口读取已归档的结构化盘面。命理负责产生个人排盘结果，账户负责归档和访问控制，合盘负责双人比较。

## 现状与交付范围

账户现有 `requestLatestDestinyArchive` 返回 `HistoryRecord`，其中 `DestinyArchive.charts` 是历史页面用的展示行。命理的 `runReading` 在计算时已有三术结构化结果，`toDestinyArchive` 写入的是展示摘要。请账户提供结构化快照的归档与授权读取能力，供命理写入、合盘读取，保留现有历史接口及旧记录的显示行为。

现有实现可参考[账户公开入口](../account/index.ts)、[归档类型](../account/history/model/contract.ts)、[命理排盘](../destiny/control/local-reading.ts)及[归档转换](../destiny/control/account-report.ts)。

## 快照写入与版本

- 每次命理测算产生一份不可变快照。记录 `snapshotId`、`schemaVersion`、来源归档 ID（若已生成）、`calculatedAt` 和时间完整度。八字、紫微、西占分别记录引擎版本、规则版本、可用状态及缺失原因。
- 盘面来自同一次已确认的测算。报告和快照如果分开写入，账户应保证关联能稳定恢复，同一次写入重试可复用快照引用。重新测算产生新版本，已固定的合盘仍引用原版本。删除或撤销授权后按账户的保留规则停止读取。
- 旧归档继续可回看。若用户选中的归档只有展示摘要，读取接口应明确返回缺少结构化盘面。合盘据此引导用户回命理确认测算，避免静默换用更早的盘面或用展示文本反推。

## 合盘需要的结构化字段

| 体系 | 最小字段 | 数据缺失时的处理 |
| --- | --- | --- |
| 八字 | 有效柱位及其天干、地支、藏干；日干、日支可由对应柱位读取；保留现有神煞及来源柱位。若已有经过确认的五行分布或喜忌字段，可随版本提供。 | 时间不完整时只向合盘提供已确认稳定的事实，并标明不可用柱位或字段。 |
| 紫微 | 命宫、身宫标识；十二宫的名称或稳定标识、地支及宫内星曜；现有生年四化及对应星曜、落宫。 | 有多个候选时辰且盘面不唯一时，标记依赖单一十二宫的比较不可用。 |
| 西占 | 热带黄道、整宫制标识；十天体标识及精确黄经、上升点、天顶、十二宫起点或等价宫位结构。 | 时间不完整时仅提供已确认稳定的星座事实。精确黄经、轴点、宫位和相位依赖的比较按现有命理口径标记不可用。 |

请将各体系定义成明确类型，并用可用性状态区分完整、部分可用和不可用。账户可在私有归档里保存命理产出的原始结构，合盘读取接口只返回上表所需字段。出生日期、时分、地点、UTC 时刻、儒略日等能重建出生资料的字段，以及个人报告正文，均不需要进入合盘读取响应。

## 读取入口与权限

请账户在公开入口提供以下能力。函数名、传输协议和类型名由账户负责人确定：

1. **读取本人最近一次已确认归档的盘面**，由服务端根据当前会员会话确定归属。区分无归档、旧归档缺结构化快照、盘面部分可用，以及认证或网络失败。
2. **读取本人指定快照版本**，用于用户确认或会话固定版本后再次读取。服务端仍须校验当前身份和该快照归属。若沿用 `expectedOwnerId`，它仅用于校验调用前后的身份一致性，访问权以服务端会话为准。

邀请模式中，双方分别登录、确认用途，并各自选择自己的快照。账户的本人读取接口只返回当前用户的盘面。若合盘后端需要取得另一方的资料，须另行约定绑定会话、快照版本和授权的服务端交接，只交付双方比较所需字段。发起方客户端只接收按权限可见的状态和合盘结果。撤销后停止新读取和后续处理。

手动模式中，账户只提供发起方 A 已归档的个人盘面。B 的临时盘面由合盘通过命理公开的纯排盘入口取得，并标记为 `manual_subject`。B 的盘面不会写入 A 的个人历史，也不需要创建 B 的账户身份。

## 联调验收

- 本人能读取同一次测算的三术快照，各体系能区分完整、部分可用和不可用；旧展示归档仍可读。
- 旧归档只含展示行时，客户端能辨认缺少快照并引导用户补齐；缺失时刻时没有补造时柱、紫微单一盘面、西占轴点或宫位。
- 另一账户或访客无法用猜测的 ID 读取会员快照；邀请链接、日志、分享摘要及本人读取响应中不暴露额外出生资料。
- 重新测算不会改变已固定的快照版本；撤销或删除后，读取方能区分数据已不可用与网络失败。

账户完成结构化归档与公开读取后，合盘在自身模块内接入读取、数据可用性判断和固定版本。跨账户邀请交接以及手动 B 方的纯排盘入口分别联调。
