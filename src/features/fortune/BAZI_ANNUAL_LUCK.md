# 八字同段岁运条件

三条太岁干合资料另由[同柱与制合事实](BAZI_ANNUAL_RELATIONS.md)计算：核心岁合可在大运未核时独立保留，涉及大运的制合见证仍只用唯一已核的当前运段；不把两种契约混为必须先有大运才能核本命岁合。

本文记录六条旧资料如何核对同一本命与唯一有效大运的条件，并保留各条来源缺项。原始资料 JSON 保留供审查，机器规则通过 SQLite 查询。当前统计见[条件映射进度](CONDITION_MAPPING_PROGRESS.md)。

## 一条事实绑定本命、岁与运

`control/bazi-annual-luck.ts` 的 `annual_luck_context` 同时保存本命柱、当前流年柱和当前大运柱。事实只在它们实际共同有效的片段内成立，沿用立春换年、上游十步大运表唯一核验和精确交运时刻；不能将不相干的流年、大运或候选盘字段拼成命中。

源依据为[《三命通会》四库本卷二固定修订761691](https://zh.wikisource.org/w/index.php?oldid=761691&title=三命通會_(四庫全書本)/卷02)。其中以甲子流年、甲子运说明岁运并临，故完整干支须都相同。新事实分别保存完整相同、仅同干、仅同支；还记录岁运两柱实际五合、四冲、六合、六冲等结构。关系存在不等于成化、合解、取用或固定吉凶。

例如1990-09-29北京时间12时、女的合成样本：2004年甲申流年落在已核甲申大运中，立春前不成立；2022壬寅年与壬午运只同干，2026丙午年与壬午运只同支，两者不能继续作为“岁运并临”的候选。缺表、错表、未知时刻、多候选和不兼容归档不提供确定大运条件。

## 十神、禄位与羊刃分支

- 岁干、岁支本气、运干、运支本气和运支全部藏干十神分别计算，参照同一日干。
- 运干财星、运支本气财星和运支任一藏干财星分别保存。第 9 条完整匹配当步运干为财且运支全部藏干无财的情形。丁日辛巳运的本气丙为劫财，巳中庚是正财，排除该情形。若要进一步判断余藏的作用和实际收获，仍须结合其他依据。
- 按[卷三固定修订657369的十干禄表](https://zh.wikisource.org/w/index.php?oldid=657369&title=三命通會_(四庫全書本)/卷03)，比本命月支与日干禄位，只证明建禄结构，不由此断为身旺或争财。
- 卷三另有“禄前一辰”的羊刃口径，本批按年干与日干两种基准分别记录支位和岁运是否到达；不在来源未定时把两种基准混成一个结果，也不用通用十二长生帝旺直接替代。十干结果依次为卯辰午未午未酉戌子丑。
- 卷三同段还有六甲乙卯、丁卯真刃与余卯偏刃的分类。事实分别保留本命年干、日干及子平五阳干的取法。原文将羊刃、七杀和财官印分说，同段并见时各自匹配，实际轻重依本命制化。
