# 八字计算层审计

基线为 `codex/destiny/birth-profile-sync` 的 `a5c4159`。

| 位置 | 基线行为 | 扩展方式 |
| --- | --- | --- |
| `control/birth-clock.ts`、`control/charts.ts` | 出生地时区和时间情景规范化。现有引擎按节气定年、月，按出生地民用时钟定日、时。 | 保留排盘规则和版本。将已有的十神、藏干与神煞计算整理为可由四柱直接调用的入口。 |
| `control/charts.ts` | 已有四柱、藏干十神和神煞。规则事实有稳定的既有字段。 | L1 复用这些产出，增加干支属性、十神索引、五行分布及月令。L2 增加确定性位置与干支关系、十神组合候选。 |
| `control/local-reading.ts`、`view/ChartPanels.tsx` | 按时刻情景运行引擎，汇总盘面，显示四柱十神和神煞。 | 完整时刻计算一次本地 L1/L2，随原始八字结果保存，在八字盘详情展示摘要。旧归档可继续读取。 |
| `requests/report.ts`、`server/report.mjs` | 传输已确认的盘面事实，匹配双层解读，模型按主题返回性格文字与事件 ID。 | 当前报告发送已确认盘面事实的中文描述，以及实际命中的书籍出处与原文、条件及现代释义，不发送完整四柱或 L1/L2 JSON，直接返回模型正文。 |

项目现有规则匹配及三种盘面的接口继续使用原有版本。L1/L2 的口径、状态和示例见本目录的计算说明。
