# 岁干与本命同柱关系及制合见证

本文记录《三命通会》卷二四条资料的机器匹配。`p267-002` 完整覆盖癸巳日遇丁亥岁的征太岁例，`p273-001` 完整覆盖日时干岁合的原文命名。`p267-004` 的甲日戊岁和 `p273-002` 的干支俱合保留来源作用条件缺项。四条均通过 SQLite 查询，源 JSON 保留原文。

## 逐条纠正查询范围

| 资料 | 原查询不足 | 本批已核计算 |
| --- | --- | --- |
| 癸巳日逢丁亥岁 | 直接比对两个干支字符串 | 生日钟核本命癸巳，立春定实际丁亥岁。从同一对柱同时查有向日干克岁干和地支六冲 |
| 甲日戊岁 | 只有日主、岁干及偏财，没有绑定制合见证 | 同一候选、年段及唯一已核大运中的庚申整柱、透出庚辛与癸、根位、支藏及巳酉丑成员分别保存 |
| 日时干岁合 | 任意本命干与岁干五合都可能入候选 | 必须本命日干或已知时干参与；仅年干、月干或其他流柱参与不能替代 |
| 干支俱合 | 分开的干合、六合可能来自不同柱，甚至无岁柱参与 | 同一太岁分别与本命四柱及实际大运核对，干合及支合须同时落在同一对柱 |

例如太岁己未，日柱甲辰提供甲己干合，年柱庚午提供午未支合，不能拼为同一柱干支俱合。另有真实命例仅生年乙与岁庚五合，日干丙和时干壬都未合岁干，也不满足日时干岁合条。原文未将干支俱合全部限定日柱，因此年、月、日、时各柱独立核对。

## 取法依据与原文分支

复核[四库本卷二数字录文](https://zh.wikisource.org/wiki/三命通會_(四庫全書本)/卷02)的〈论太岁〉、〈总论岁运〉及〈论十干合〉。这是录文核读，不冒称原刊影印。录文有己、已、巳字形混用，天干五合语境按己干处理，不把巳支套入天干；原JSON保留原字，未覆写资料。

癸巳日对丁亥岁同时取得癸水克丁火与巳亥六冲，所以可确认这一组原例。原段另列大运伤冲太岁、太岁冲日等方向，须分别核对。此例即使大运表未核也能判断两柱关系，实际救应仍须另外计算。

本命干在前、岁干在后，甲日己岁与己日甲岁分别保存为原文相对较重与较轻的有向例。

### 日时干合与俱合的分支

日时干合的 SQLite 查询读取实际合干参与柱。以本命日柱为起点，分别核十二支和六十干支顺逆五位。日或时干实际合岁干时，顺推五位纳入“日前五辰”的入宅候选，分记整柱吻合与只到同支。逆推位置单独保留。出生时刻已核的案例沿用[人元司事首表](BAZI_ANNUAL_LUCK.md#人元司事的两份日数)，用实际交节核出生月内候选。 [卷二〈总论岁运〉](https://www.shidianguji.com/zh/book/SK1610/chapter/1kf5v6ol1wjl1)

有效干支中，天干五合对应阴阳相异，地支六冲对应阴阳相同。日时干合后分别核岁支和合干所在柱与其他已知柱的六冲。日干、参与干各自起十二宫，记录临岁支的阶段与同段冲位。底本此处有“日轉時重”的字样，模块按《古今图书集成》所引《神白经》的“日轻时重”分别标记实际参与的柱。日时柱位和甲己方向是两项独立比较。人元实际旺衰、死绝取法、岁位其他近远范围和两项同时出现时如何取舍仍待核。 [《古今图书集成》艺术典卷五百九十八](https://www.shidianguji.com/zh/book/GJTS17/chapter/1lpxdiep8bciu)

## 事实、未知与时间

`control/bazi-annual-relations.ts` 输出 `annual_column_relations`。有明确出生地时钟时按归档 UTC、出生地时区与对应日期复核日柱和时柱，年、月沿用北京时间的交节瞬间。旧档按声明的北京时间核对，未知时刻只使用可复核的已知柱位。

与大运有关的字段只使用完整十步表唯一核验的实际运段。童限不虚造运柱，未核方案也不选某一个候选冒充已知。窗口在立春和真实交运时刻切分，出生年只从出生时刻开始；北京交节仍是模块声明的实现口径，不冒称原书规定现代时钟细则。

已知日干或已知柱满足时可以形成候选；日干未合且时干未知，不能断日时干均不合；已知三柱无俱合不能排除未知时柱。多候选由现有资格层继续排除拼接。

新增第66种显式中文投影，每个实际岁柱和大运配置留一份带时间范围的代表，避免公历年初的上一岁掩盖立春后的主年或交运后内容。甲日戊岁制合细节只在该前提成立的片段表达。内部字段、数组、查询、原始盘面和资料ID留本地。部分映射的条目只在其独立确认的片段提供对应短引。
