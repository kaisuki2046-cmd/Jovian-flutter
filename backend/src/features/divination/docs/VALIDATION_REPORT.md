# 算事新版验收记录

基线 `eff1751`。在现有 Expo、Node 和 SQLite 模块内实现，复用锁定的 `lunar-javascript`、本地牌面与牌义。源码与现有启动入口放在同一仓库。

- 新版测试覆盖 4,096 组六爻变化、384 组梅花上下卦与动爻、泽天夬变天风姤、纯乾坤互卦、同毫秒和时间回拨。
- 使用实际历法库核对北京时间 23 点换日，并确认跨 23 点投币仍使用第一投的日柱。
- 隔离 SQLite 验证重启后恢复、78 个可选槽位、同一事件回放、参数冲突拒绝和重试报告时保持原盘。78 张牌面与牌背通过 [SHA-256 清单](../data/asset_manifest.json)校验。
- 使用虚构面试问题联调 DeepSeek Flash 官方 API。解析成功并生成三段观察和三条行动建议，追问前后盘面哈希一致。

类型检查、模块边界检查和 39 项算事测试通过。运行 `npm run typecheck`、`npm run check:boundaries` 和 `npm test -- src/features/divination`。

待验收包括浏览器逐项交互和各节气的独立历表校准。指导稿中的逐字段引用、候选事项版本、自然语言日期解析、完整历史导出和飞牌至选中区的动画仍待实现。当前采用单次解析或解读请求及手动重试，尚未实现自动退避与 JSON 修复。
