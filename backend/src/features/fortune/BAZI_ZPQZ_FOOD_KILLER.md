# 《子平真诠评注》食神生财与带杀条件

对应 p089 至 p096 八条。原文、释义、条件和源哈希保留在 JSON，机器规则导入 SQLite。p090 的沈、龚两例已核完。其他条目的具名确认限于原评和实排条件共同成立的运段。

## 原章与前置条件

核对[NCC卷五食神及取运录文](https://www.ncc.com.tw/fate/paleo/bg/bg_035.htm)，不冒称已核原刊影印。梁、谢、沈、龚、常、胡、刘、李、透财解印、舒、钱、黄十二图逐柱保留，年月及日时干配分别校核；录图同构不代表实际生日或历史本人。

食神带杀三分支共同承接原局无印绶，不能只给第一分支保留该前提。本轮给p091、p092、p093同时核完整透干与支藏无印；时柱未知不能认定全局无印。带印用杀和无印带杀不能混用，三分支的身弱、身旺杀强和杀轻食重仍分别待核。

## 柱位、根与命例分歧

`control/bazi-zpqz-food-killer.ts`复用已有透藏、柱序、根位计算，分别记录食、伤、财、印、杀实际位置。食伤生财、食伤制杀、财生杀和印克食伤保存具体两端与中间柱，不把几何关系当有效救应。

梁例原局亥卯未齐全，沈例只有亥卯，不借寅补成三合。原局成员、运来补支和已成化分开。梁例另透壬合丁是原文假设；原局壬丁与大运壬合丁分别记录，不把后者冒充前者。

胡例戊戌、壬戌、丙子、戊戌，原局无木印，但三个戌仍藏辛财。食神章对胡例不宜财的评语，与取运段财反吉的概括须保留身旺弱语境，不能擦除支藏财或统一成财运皆吉。

透财解印例己亥、丙寅、甲寅、壬申，己财在已知支藏中没有同干己根，寅申却有同五行戊。产品同五行根位不能直接替代原文己财无根、解救无力的取义，更不能按根数判药力。

刘例癸财在年、辛食在月、乙杀在时，中间含实际日柱，财先食后的位置保留；并不据此宣布财已不党杀或身杀已平衡。

舒例辛日，子中癸为食神、壬干为伤官、丁干为七杀；钱例甲日丙为食神。章中金水食神、官星或木火伤官的统称不更改具体十神。夏月木日和冬月金日只作历法候选，不自动定寒燥；黄例无印与钱例带印保持区别。
