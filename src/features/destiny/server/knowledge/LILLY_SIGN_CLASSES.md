# 莉莉星座类别与明确对象接线

本轮在命理目录接通15条原未映射记录、35个条件备选，见 [批次清单](claims/integration-batch-24-20261119.json) 和 [原生排盘见证](claims/integration-batch-24-witnesses.json)。原三库JSON、18,846个ID、原文与出处不改，仍经统一SQLite检索。前23批的2,769条可查询记录保持完整编译快照不变。

## 来源与分类

来源核对采用《Christian Astrology》Book I印刷pp.87–90的分类及Book III pp.601、632–633、636的具体条件；可复核 [Book I](https://www.worldastrology.net/wp-content/uploads/2008/12/CA-I.pdf#page=107) 和 [Book III](https://www.worldastrology.net/wp-content/uploads/2008/12/CA-III.pdf#page=115)。Book III pp.598、601的来源记录仍保留提供资料所据1647初版影印链接，没有以公开转录改写源文。

- 活动、固定、变动三类使用原列的十二星座分组，四元素使用Book I的三方分组。
- 回归座只取巨蟹、摩羯，依据Book I p.90的两回归座定义，不混成四个活动座。
- 人形组取双子、处女、天秤、水瓶。
- 职业p.632的四足组明确只列白羊、狮子、射手。Book I其他段的范围更宽，本条不借用其金牛、摩羯。

这些是历史类别，不是对用户人格、身体特征、婚姻次数或职业身份的现实判定。

职业类别先用 [现有职业选星前两步](LILLY_PROFESSION.md) 确认实际成员，多个成员分别核对。不能拿水星的成员身份与金星的元素类别拼成一组。规则保留确切的三成员择一；否定时必须逐一排除全部三组，未知不作否定。后续月亮选星、强势相位移交、木金水共同参与等未实现方法仍待核，不借分类接线冒充完成。

## 查询与防伪

`lilly-sign-classes.mjs` 从确认的星座／黄经和历史宫头计算类别。唯一已知星座足以分类，不凭空补精确度数；若同时提供黄经，必须一致。重复冲突的位置不输出类别或负面证据。

宫头与宫主使用经校验的Regiomontanus十二宫头，定位星通过SQLite原尊贵单元取得。新增派生字段在请求解析和直接查询中都重算，客户端传入的正面或缺席标记均不能代替计算；只有实际已知不属于某类时才提供反证。未知出生时间仍去除相关宫位和职业选择条件，保留源条目原有门槛。

运行中没有扫描JSON来分类检索。JSON保持可审查源，编译成实际SQL条件；条件核对及单条解释使用相同事实，报告只接收满足条件的材料，并将具体对象和类别转换为中文。
