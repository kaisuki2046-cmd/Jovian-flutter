# 《全书》空劫与四飞星来源事实

扩充条目 `p017-001`、`p038-001`、`p039-001` 使用空劫安星和同段岁限事实。三条均为部分映射。全库统计见 [条件映射进度](CONDITION_MAPPING_PROGRESS.md)。

## 古天空的身份核验

[卷二固定修订1963110](https://zh.wikisource.org/w/index.php?oldid=1963110&title=紫微斗數全書/卷二)的“天空地劫诀”以亥宫起子时，顺数生时安地劫、逆数安天空。书内明列子时二星在亥、丑时劫在子而空在戌、午时二星在巳。`control/ziwei-kongjie.ts` 独立实现这一计算，不调用引擎的安空劫函数。

兼容、可核定的归档盘中，重算古天空的位置须与唯一归档“地空”一致，重算地劫的位置须与唯一归档“地劫”一致。星名对应只在本条安星计算及位置核验中成立。现代另名“天空”的星位单独保留。缺少一星、重名或错位时，该星待核，已核的另一星仍可进入自己的查询。双星分支须两颗均可核。出生时支不确定、闰生月及不兼容版本下，两星都待核。

时支每转一位，二星分别逆顺移一宫；子时亥、午时巳的共宫是计算结果，其余十个时支分宫。计算结果只说明实际共宫与分宫，不自行解释[卷一空劫问答](https://zh.wikisource.org/w/index.php?oldid=7913704&title=紫微斗數全書/卷一#問天空地劫所主若何？)是否要求二星同时到某限。该问答的遇吉、遇凶与四杀冲照仍须核完整条件，不由单星或共宫推出资源损失。

## 四飞星与年段

同一卷二的四飞星诀以流年太岁支定位：前二宫丧门、后二宫吊客，丧门对宫白虎、吊客对宫官府。`quanshuFourFlying` 按这一明列规则独立重算，保存原文“官府”的写法。其坐标与当前引擎年度岁前“官符”在十二年循环中相合，但坐标相同不代表可以把其他段落的“官符”、博士串“官府”或太岁煞任意归并成一颗星。

`quanshu_kongjie_condition` 在每个实际大限、小限或流年命宫保存：

- 出生时支、重算古天空及地劫的位置、唯一归档核验、现代另名天空的位置。
- 本层命宫相逢的来源空劫名称，二星是否实际共宫；不跨宫拼成同宫。
- 该段农历年、太岁支、四飞星的地支，以及它们相对本层命宫的同宫、对宫、三合，分开保存。
- 兼容归档本宫已有主星；仅为位置背景，不等于正曜加吉、吉众或救应已经成立。

原大限宫位可能跨农历新年保持不变，底层会合并成一个限段。空劫事实必须再与各个实际流年段求交，因此同一个大限仍会在新年切换四飞星，不把查询窗第一年的四飞星沿用到下一年。边界使用明确声明的产品农历新年、北京午夜与虚岁口径，不声称重建全部原书起限法。

### 分宫的守照与具名星位
