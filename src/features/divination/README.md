# 算事

- **职责**：维护算事输入规则和解读格式，管理算事原文，按需通过账户公开接口读取获准使用的默认主题。
- **可能输入**：用户提交的问题、所选主题或默认主题。
- **预期产出**：算事解读结果，以及可交由账户模块归档的内容。

## 本地体验

从「算事」对话说出想问的事情或方向。可以直接问「这件事多久有结果」或「什么时候回款」，当前进展和日期都是可选背景。只有没说要问什么，或同时提出几件独立的事，才会请你补一句或先选一件。进入仪式后先投六次铜钱，再从 78 张塔罗牌中选三张。服务器保存三次选牌的完整毫秒值并计算梅花卦。完成排盘后自动生成 Pro 解读，按塔罗、梅花易数、六爻展示，盘面可展开查看。

| 术法 | 本地计算 | 解释依据 |
| --- | --- | --- |
| 塔罗 | 78 张牌洗牌并分别固定正逆位，按现状、关键影响、趋势选取 | 本地牌面和牌义库 |
| 六爻 | 京房八宫、纳甲、世应、六亲、六神、旬空、伏神、动爻与变卦 | 第一次投币锁定北京时间，子初换日，以节换月 |
| 梅花易数 | 三次点击使用完整 Unix 毫秒，按先天数计算上下卦、动爻、互卦、变卦和体用 | 按选择顺序保存原始时间，允许同毫秒或时钟回拨 |

问题解析使用 DeepSeek Flash。首次解读由 DeepSeek Pro 使用原问题和三套原始盘面生成，按塔罗、梅花易数、六爻分别展示。解读按段呈现，关键短语加粗，每段依据可展开。对话输入框可以接着上一题问，也可以另问一件事。报告内的「发送追问」可沿用这一次的盘面，追问和回复随原报告保存。已经创建的仪式可以断开外网继续排盘，解读失败后可重试同一盘面。启动和密钥配置见[算事服务](server/README.md)。

## 计算与恢复

- 塔罗入口位于 `control/tarot-session.ts` 和 `control/tarot.ts`，六爻位于 `control/liuyao.mjs`，梅花位于 `control/meihua.mjs`。三个本地计算入口共享仓库已有的牌义或卦象资料。
- `server/reading-tasks.mjs` 保存抽牌、投掷原始记录、结果及证据。快照记录每种术法的规则版本，任务操作重试沿用已保存记录。服务器重新启动后，可用原令牌恢复本次任务。
- 新任务保存 [three-methods-v1 规则档案](data/rule_profiles/v1.json)、原始事件和盘面哈希。旧综合任务继续使用原版本规则。
- 会话历史、恢复令牌和待重试的仪式动作按当前会员或游客身份隔离。无有效身份时，会话只保留在当前页面内存中。旧版本的无归属记录保留在原存储位置，界面只加载带当前身份的记录。
- Web 同一标签页或原生端可以恢复当前身份最近的未完成任务，任务有效期 24 小时。已保存的会话可从「会话历史」搜索和查看。同一 Web 预览地址下，本机算事服务改用备用端口时仍可查看当前身份的历史。未完成任务的恢复凭据按完整服务地址保存。
- 附件用于当前对话内展示。算事服务接收输入的文字。Web 历史保存附件名称。
- 已有独立算事任务仍可恢复。通过聊天记录可以打开单项任务的独立页面，继续操作或阅读结果。独立算事 HTTP 接口继续可用。
- `server/pro-report.mjs` 组织首次解读的模型输入并加载 Pro 提示词，`server/combined-report.mjs` 处理追问及旧版报告。排盘事实由服务器计算，界面从任务快照展示。

> **跨板块协作**　其他板块的代码可以阅读和参考，可通过对方明确开放的入口或公共 UI 复用能力。需要修改认领范围外的文件时，包括其他板块的代码、业务页面和说明文档，须先向用户说明具体文件、原因和影响，取得明确授权后再修改。

## 协作约束 v1.2

本目录归 `src/features/divination/` 管理；默认只改认领范围及本任务相关的 `src/ui/`。业务模块之间不能相互改文件，修改其他目录前 Codex 必须先向用户询问具体范围和影响，获得明确授权后再做。独立认领更小子目录时按更小范围执行。

业务目标采用 `model/`（数据）、`view/`（具体 UI）、`control/`（功能），现有文件按后续任务渐进整理，不表示已迁移。业务请求仍留在本模块 requests；公共 UI 只接收数据、状态和回调。

按 MVP 验收逐步迭代。公共 UI 的破坏性接口或全局风格变更先向用户确认；提交只包含本轮范围，保留并行改动，结束时列出实际目录、共享组件影响和验证。详细规则见 [本目录开工说明](AGENTS.md)、[协作协议](../../../COLLABORATION.md) 与 [框架图](../../../FRAMEWORK.md)。
