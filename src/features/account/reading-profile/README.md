# 占卜资料

- **职责**：管理当前用户的出生日期、时间和地点等占卜资料，向有权限的调用方提供所需字段。
- **可能输入**：当前用户身份、出生资料更新或指定字段的读取请求。
- **预期产出**：获准读取的占卜资料字段或更新结果。

完整出生资料保存在账户内部 SQLite 表 `account_reading_profiles`。仅账户内部服务通过存储适配器的 `getReadingProfile(userId)` 读取；其他模块不得直接访问数据库或存储文件，需先约定用途和字段，再使用账户明确交付的公开接口。本人在「基础个人资料」中维护出生年月日、时间、地点、性别及四项独立的可见性设置。

其他已登录用户查询出生资料时，每项默认保密，开启可见且填写了值的字段才会出现在查询结果中。

## 跨板块读取

从账户公开入口调用 `requestAccountBirthProfile(expectedOwnerId, fields, signal?)`。例如，需要预填日期和时间时调用 `requestAccountBirthProfile(memberId, ['birthDate', 'birthTime'], signal)`。

可选字段为 `birthDate`（YYYY-MM-DD）、`birthTime`（HH:mm、HH:?? 或 ??:mm）、`birthPlace`（用户保存的地点文字）和 `gender`（`female`、`male`、`other`）。未填写的字段返回空字符串。调用方按用途选取字段，并在使用地点进行测算前按自己的地点目录核对。

命理可在用户确认后调用 `confirmAccountBirthProfile` 写入同一份账户资料。账户保留个人中心已有的可见性设置，并检测另一端的并发修改。 [命理同步接入说明](DESTINY-BIRTH-PROFILE-SYNC.md)

读取需要有效会员会话，返回本人所请求的字段。访客或失效会话返回 401，身份变化返回 403，缺少或传入无效字段返回 400。调用方在身份变化时中止请求并清除旧数据。本人读取与他人可见性分别由账户校验。推荐用途仍需单独授权，社交读取使用获准对他人展示的资料。

测算结果可通过 [命盘快照接口](../history/README.md#读取完整命盘) 读取。出生资料和命盘归档分别保存，用户之后编辑资料时，历史命盘仍对应当次测算。

> **跨板块协作**　其他板块的代码可以阅读和参考，可通过对方明确开放的入口或公共 UI 复用能力。需要修改认领范围外的文件时，包括其他板块的代码、业务页面和说明文档，须先向用户说明具体文件、原因和影响，取得明确授权后再修改。

## 协作约束 v1.2

本目录归 `src/features/account/reading-profile/` 管理；默认只改认领范围及本任务相关的 `src/ui/`。业务模块之间不能相互改文件，修改其他目录前 Codex 必须先向用户询问具体范围和影响，获得明确授权后再做。独立认领更小子目录时按更小范围执行。

业务目标采用 `model/`（数据）、`view/`（具体 UI）、`control/`（功能），现有文件按后续任务渐进整理，不表示已迁移。业务请求仍留在本模块 requests；公共 UI 只接收数据、状态和回调。

按 MVP 验收逐步迭代。公共 UI 的破坏性接口或全局风格变更先向用户确认；提交只包含本轮范围，保留并行改动，结束时列出实际目录、共享组件影响和验证。详细规则见 [本目录开工说明](AGENTS.md)、[协作协议](../../../../COLLABORATION.md) 与 [框架图](../../../../FRAMEWORK.md)。
